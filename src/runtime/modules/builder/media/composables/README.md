# builder/media/composables

| Файл                         | Назначение                                                                                         |
| ---------------------------- | -------------------------------------------------------------------------------------------------- |
| `useMediaUpload.ts`          | Загрузка файлов в медиа-галерею: лимиты из app config, валидация типа/размера, media store         |
| `useSchemaImageResolver.ts`  | Резолвинг изображений при импорте JSON-схемы: модалка выбора (оставить / заглушка)                 |
| `useMediaCategoryActions.ts` | Создание и удаление категорий медиатеки: флаги записи, подтверждение удаления, текст подтверждения |
| `useMediaGalleryFileDrop.ts` | Приёмник файлов галереи: счётчик тащимых файлов, `drop`, страховка от залипшего оверлея            |
| `useMediaMetaDrafts.ts`      | Черновики имени и alt выбранного файла: коммит по уходу фокуса, защита ввода от ответов сервера    |
