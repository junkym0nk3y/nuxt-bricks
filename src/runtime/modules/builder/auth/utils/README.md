# builder/auth/utils

| Файл                  | Назначение                                                                             |
| --------------------- | -------------------------------------------------------------------------------------- |
| `redirects.ts`        | `sanitizeRedirectPath()` — только внутренние пути, защита от open redirect             |
| `validationSchema.ts` | Yup-фабрики схем логина, профиля и смены своего пароля (сообщения-функции с `t()`)     |
| `avatarCropFrame.ts`  | Чистая математика рамки кадрирования: клампы, потолок масштаба, минимальная сторона    |
| `profileErrors.ts`    | Отказы ручек профиля → i18n-ключи (аватар различается статусом, пароль — кодом отказа) |
