# builder/core/utils

| File                     | Purpose                                                                                                                                                                                                                                   |
| ------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `canvasFlow.ts`          | Silencing the move transitions of the canvas flow (`bricks-canvas--flow-instant`) for the frames where the geometry changes without the blocks being rearranged                                                                           |
| `componentMovePolicy.ts` | `evaluateComponentMove` — the single rule of a permitted move for every surface (the tree, the canvas, the slots): a cycle, the depth of the schema contract, a container, the capacity of a Grid and of a slot                           |
| `componentTree.ts`       | Walking the component graph over all three sources of the links at once (`children`, the slots, the `parent` of the child): the adjacency, the subtree check, the height and the depth — each of them survives an already corrupted draft |
| `history.ts`             | Bounding the size of the undo/redo history and the position of its index                                                                                                                                                                  |
| `ids.ts`                 | `generateComponentId`/`generateNavigationItemId` — the ids of canvas components and of navigation items; `Math.random` rather than `crypto.randomUUID` (that one exists only in a secure context) and not a hash dependency               |
| `inlineEditableProp.ts`  | Finding the inline-editable props of a layout block and of a brick component (`input` counts for a brick, but not for a layout — there it would catch the CSS props of Media)                                                             |
| `layoutChildren.ts`      | The mechanics of the children list of a layout: the grid placement of a child on a move and the two models of a rearrangement inside the list (a plain move and the Grid swap, where both participants give up their cells)               |
| `layoutProperties.ts`    | A thin wrapper over the registry of the layout blocks: the property configuration by layout name                                                                                                                                          |
| `scrollToComponent.ts`   | Scrolling the canvas to a component by id (scoped to the viewport in Figma mode)                                                                                                                                                          |
| `slots.ts`               | Initializing the slots of a layout component out of the brick metadata                                                                                                                                                                    |
| `dragVisuals.ts`         | A light skeleton drag image with no cloning of the DOM, the CSS variables of the placeholder size and `buildDropFlowEntries` — the keyed flow "the blocks + the insertion place" for a `TransitionGroup`                                  |
| `deviceKeyCleanup.ts`    | Clearing the schema of the keys of vanished devices (`stripDeviceKeysFromSchema`) and diffing the sets (`findRemovedDeviceKeys`). Applied to the history snapshots too: an undo must not bring back the overrides of a deleted step       |
