# builder/core/composables

| File                                | Purpose                                                                                                                                                                                                                                                              |
| ----------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `useBrickMetadata.ts`               | An index of brick metadata by `brickPath` out of the response of the components endpoint: `replaceBrickMetadata` (written by `useComponentLibrary`), `readBrickMetadata`; the types are in `../types/componentLibrary.d.ts`                                          |
| `useBuilderPermissions.ts`          | The permissions of the session by role (`canEdit`/`canDelete`/`canManageUsers`): the role arrives out of the request context on SSR, `ensureRole(fetchRole)` is the composition root's fallback for builds without SSR; the types are in `../types/permissions.d.ts` |
| `useBuilderPreferences.ts`          | The shell preferences shared by the dashboard and the editor: the dark theme (the cookie plus the `body` class) and switching the locale of the interface; the types are in `../types/preferences.d.ts`                                                              |
| `useBuilderToast.ts`                | The state of the builder's toast notification: showing one (`showToast`), a toast with an action and no auto-hide (`showActionToast`) and putting out one's own by the number of the showing (`hideToast`); the types are in `../types/toast.d.ts`                   |
| `useComponentMoveFeedback.ts`       | Telling the user why a move was refused: the machine-readable reason of the rule → a locale key → a toast; the programmer-level reasons fold into one common message                                                                                                 |
| `useComponentEditorMetadata.ts`     | The data of the properties panel for a canvas component: either the layout definitions or the metadata index; one resolver for a selection by click and through the schema tree                                                                                      |
| `useComponentProperties.ts`         | Working with the properties of components: loading the properties out of a brick, the variants of select/tabs/modal-select                                                                                                                                           |
| `useModalOptions.ts`                | The cache of the modals out of the manifest of the brick components: `replaceModalsCache` (filled by the response of the components endpoint out of `useComponentLibrary`), `getModalOptions` (the options of a selector); the types are in `../types/modals.d.ts`   |
| `usePropertiesPanelAvailability.ts` | Keeps the sidebar store aware of whether the right-hand properties panel is mounted: watches `canEdit` and puts out `right.visible`, otherwise the canvas would subtract the width of a panel the role does not have                                                 |
