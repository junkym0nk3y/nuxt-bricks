# Медиагалерея

Медиагалерея — это хранилище изображений и медиафайлов, которые вы используете в компонентах лендинга. Загруженные файлы автоматически оптимизируются и становятся доступны во всех блоках, где есть поле для изображения или видео.

## Как открыть галерею

Нажмите кнопку **Медиагалерея** в правой части верхней панели.

![Медиагалерея](./images/media-gallery.png)

## Категории

Файлы в галерее распределены по категориям:

| Категория       | Описание                               |
| --------------- | -------------------------------------- |
| **Все**         | Все загруженные файлы                  |
| **Иконки**      | SVG-иконки и мелкая графика            |
| **Иллюстрации** | Декоративные изображения и иллюстрации |
| **Фотографии**  | Фотоматериалы                          |
| **Другое**      | Файлы без категории                    |

Используйте фильтр по категориям и строку **Поиск** (по названию или alt-тексту), чтобы быстро находить нужные файлы.

## Загрузка файлов

1. Откройте медиагалерею.
2. Перетащите файл (или несколько файлов) в область загрузки. Также можно нажать кнопку **Выбрать файлы** и выбрать файлы через диалоговое окно.
3. Изображение будет автоматически оптимизировано и загружено в облачное хранилище.

При загрузке для каждого файла отображаются: название, размер файла и присвоенная категория.

## Выбор изображения для компонента

1. Выберите блок на канвасе.
2. В панели свойств найдите поле с типом «Изображение».
3. Нажмите кнопку **Выбрать** — откроется медиагалерея.
4. Выберите нужное изображение.

Изображение будет привязано к свойству компонента и сразу отобразится на канвасе. Для удаления привязки нажмите **Удалить** рядом с превью.

## Рекомендуемые форматы

| Формат   | Когда использовать                                   |
| -------- | ---------------------------------------------------- |
| **WebP** | Основной формат. Хорошее сжатие при высоком качестве |
| **SVG**  | Иконки, логотипы, простая графика                    |
| **PNG**  | Изображения с прозрачностью                          |

> Загруженные изображения растрового формата - автоматически будут оптимизированы и конвертированы в формат webp
