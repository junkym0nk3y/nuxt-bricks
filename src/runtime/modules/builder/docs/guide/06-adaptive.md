# Адаптивность

Конструктор позволяет проверить и настроить отображение страницы для разных устройств: мобильных телефонов, планшетов и десктопов.

## Переключение viewport

Над канвасом расположена панель с переключателями устройств:

![Панель viewport](./images/viewport-panel.png)

| Режим          | Ширина | Описание                           |
| -------------- | ------ | ---------------------------------- |
| **Mobile**     | 375px  | Мобильные телефоны                 |
| **Tablet**     | 768px  | Планшеты                           |
| **Desktop**    | 1600px | Десктопные экраны                  |
| **Figma Like** | 100%   | Занимает всю доступную ширину окна |

При переключении режима ширина канваса изменится, и вы увидите, как страница будет выглядеть на выбранном устройстве.

### Режим Figma Like

Режим **Figma Like** растягивает канвас на всю доступную ширину окна браузера (за вычетом боковых панелей). Удобен для точной проверки вёрстки, когда вы хотите видеть контент в реальном масштабе, без ограничения фиксированной шириной.

> В каждом из представленных адаптивов - внутри канваса есть возможно перемещаться вертикально и горизонтально, как это реализовано в Figma (зажмите на мыше кнопку scroll)

## Скрытие блока на определённом устройстве

Вы можете показывать или скрывать любой блок в зависимости от устройства.

1. Выберите блок на канвасе.
2. В панели свойств найдите секцию **«Отображение»**.
3. В строке **«Показывать на»** выключите ненужное устройство.

**Пример:** слайдер-карусель удобен на мобильных, но на десктопе лучше показать статичную раскладку. Создайте два варианта: слайдер со скрытием на десктопе и Flex-контейнер со скрытием на мобильных.

## Адаптивные свойства layout-контейнеров

Layout-контейнеры **Section**, **Space**, **Media** и **Svg** (а также **Grid** и **Flex**) поддерживают адаптивные настройки — возможность задать разные значения свойств для каждого устройства.

### Как настроить

1. Выберите layout-контейнер на канвасе.
2. В панели свойств над секцией «Свойства» появятся вкладки **Desktop / Tablet / Mobile**.
3. Переключитесь на нужное устройство (например, Mobile).
4. Измените значение свойства — оно будет применяться **только** на выбранном устройстве.
5. Для остальных устройств будет использоваться значение Desktop (базовое).

> При переключении viewport канваса вкладка устройства в панели свойств переключается автоматически. В режиме Figma Like вкладка по умолчанию — Desktop.

### Какие свойства поддерживают адаптивность

Не все свойства адаптивные — только отмеченные в определении. Вот текущий список:

**Section:**

- paddingTop, paddingBottom, paddingX (отступы)
- borderRadius (скругление)
- minHeight (минимальная высота)

**Space:**

- size (величина отступа)
- dividerMarginX (отступы разделителя)

**Media / Svg:**

- width, height (размеры)
- borderRadius (скругление, только Media)

**Grid:**

- columns, rows, gap, variant, rowHeight, minRowHeight

**Flex:**

- direction, justify, wrap, gap

### Пример

Допустим, вы хотите, чтобы секция имела большие отступы на десктопе и маленькие на мобильных:

1. Выберите секцию, убедитесь что вкладка **Desktop** активна.
2. Установите paddingTop = `6` и paddingBottom = `6`.
3. Переключитесь на вкладку **Mobile**.
4. Установите paddingTop = `2` и paddingBottom = `2`.

На опубликованной странице отступы автоматически переключатся через CSS media queries.

## Разные значения свойств для разных устройств (через парные свойства)

Некоторые пользовательские компоненты поддерживают отдельные настройки для каждого устройства через парные свойства в story-определении. Это позволяет, например, показывать короткий заголовок на мобильных и полный — на десктопе.

Типичные примеры:

- **title** / **mobileTitle** — разные заголовки для десктопа и мобильных.
- **mediaDesktop** / **mediaTablet** / **mediaMobile** — разные изображения для каждого устройства.
- **slidesPerViewMobile** / **slidesPerViewTablet** / **slidesPerViewDesktop** — разное количество слайдов в карусели.

Если у компонента есть такие парные свойства, они будут видны в панели свойств. Заполните оба поля, чтобы контент корректно отображался на всех устройствах.

> Парные свойства — это подход на уровне компонента (story). Адаптивные свойства layout-контейнеров (описанные выше) — встроенный механизм билдера, работающий через CSS-переменные и вкладки устройств.

**Совет:** всегда проверяйте все три режима (Mobile, Tablet, Desktop) перед публикацией страницы. Также используйте режим Figma Like для проверки промежуточных разрешений.
