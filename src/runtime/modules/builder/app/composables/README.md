# builder/app/composables

Composables of the builder's composition root (assembled by the `builder.vue` /
`[pagename].vue` pages).

| File                              | Purpose                                                                                                                                                                                                                                        |
| --------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `useBuilderPage.ts`               | Facade of the builder page: assembles the business logic and hands the component only the states it needs                                                                                                                                      |
| `useBuilderPageWrite.ts`          | Writing the open page: saving (draft/publication) and Save as Copy — the session move, the preview shot, outcome toasts carrying the page context                                                                                              |
| `useBuilderPageChrome.ts`         | The dress of the editor page: the theme and the language shared with the dashboard (`core/useBuilderPreferences`), the title and the `body` class through `useHead`, the sign-out with a toast on a refusal                                    |
| `useBuilderPageSelector.ts`       | Page selector of the toolbar: loading the rest of the list and refreshing it, moving to the chosen page, the creation modal (with the resolver of imported images)                                                                             |
| `useBuilderSessionAddress.ts`     | Owner of the session address: `routeAddress` (URL) + `sessionAddress` (the drafts key), `renameSession` (migration + router.replace); an address is the pair `urlPrefix + pagename`                                                            |
| `useBuilderSession.ts`            | The session: opening a page by address, discovering a draft, `isSessionReady` for the autosave; a rename does not reopen the session                                                                                                           |
| `useBuilderSessionFeedback.ts`    | What the person sees of the state of the session: the loader, the `inert` barriers over the interface and the workspace, the toast offering to restore a draft (raised only once the loader has left)                                          |
| `useBuilderSessionSnapshot.ts`    | The saved state of the session as one invariant: `savedSnapshot`, the draft under the session key and `sessionPageId` — the commit and the move onto a saved page (Save as Copy) write all three together                                      |
| `useBuilderDraftPrompt.ts`        | The offer to restore a discovered draft: the "no answer yet" state (which forbids the autosave), the window of the choice and its three outcomes — restore, delete, postpone; lifted by the first edit a person makes                          |
| `useBuilderSessionToken.ts`       | The session token: an operation takes it at the start and checks it before writing the result; the increments are owned by `useBuilderSession` (opening + dispose)                                                                             |
| `useBuilderDraftPersistence.ts`   | Autosave of a draft into localStorage (debounce 800 ms) under the `sessionAddress` key, a flush on `pagehide` and on the stop of the scope, deletion when there are no changes                                                                 |
| `useBuilderSessionAddressSync.ts` | Syncing the URL with the address of the publication form (debounce 600 ms → `renameSession`; watches the pair `pagename + urlPrefix`; guards: the format, a taken editor address, an address taken by another page)                            |
| `useBuilderTemplateSave.ts`       | Saving the canvas as a template: the source is assembled synchronously out of the canvas (unsaved edits included), the thumbnail is the frame of the page's last save                                                                          |
| `useBuilderShortcuts.ts`          | Keyboard shortcuts: Delete/Backspace, Ctrl/Cmd+C/V, undo/redo, Escape (clearing the selection)                                                                                                                                                 |
| `useComponentLibrary.ts`          | Loading the component library: the bricks from the backend + the `.brick.ts` metadata + the layout blocks; the same response fills the modals cache (`core/composables/useModalOptions`), while the refusal flag and the retry travel outwards |
| `useDraggableComponent.ts`        | Drag-and-drop of components from the library onto the canvas                                                                                                                                                                                   |
| `usePageThumbnail.ts`             | The page's preview for the dashboard: a snapshot of the canvas (modern-screenshot, lazy) → S3 → PATCH `thumbnailUrl`; fire-and-forget                                                                                                          |
| `usePreviewSync.ts`               | Syncing the schema with the preview tab through a BroadcastChannel (debounce 300 ms)                                                                                                                                                           |
