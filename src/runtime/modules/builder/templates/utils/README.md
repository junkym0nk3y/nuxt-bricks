# builder/templates/utils

| Файл                  | Назначение                                                                                                                                 |
| --------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| `templatesApi.ts`     | Запросы `/api/bricks/templates/**`: список сводок, полный шаблон point-lookup'ом, создание, правка подписи, удаление                       |
| `templateErrors.ts`   | Разбор отказов: занятое имя (`TEMPLATE_NAME_CONFLICT`) под поле, ключи текстов по статусу, «раздела в установке нет» (404 первой загрузки) |
| `templateSummary.ts`  | `toTemplateSummary` — полная строка из ответа записи → сводка списка (число блоков считается из схемы: в полной строке его нет)            |
| `validationSchema.ts` | Yup-схема формы шаблона (имя и описание) — общая для сохранения и переименования; границы из `common/constants/templates.ts`               |
