# builder/publish/composables

| File                                | Purpose                                                                                                                                                                                                                                                                           |
| ----------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `usePublishDashboard.ts`            | The state of the pages dashboard: the debounced search, the segment filter, the filter counters                                                                                                                                                                                   |
| `usePublishPagesData.ts`            | Loading the pages list into the store on SSR (`useAsyncData`) + a client-side retry after the server refuses                                                                                                                                                                      |
| `usePublishPageForm.ts`             | The local meta form of the details panel: vee-validate + the shared schema, dirty detection, saving through `patchPage`                                                                                                                                                           |
| `usePublishCreatePageForm.ts`       | The form of the page creation modal: auto-slugify off the title, the shared schema, creation through the store's `createPage`                                                                                                                                                     |
| `usePublishDetailsUrl.ts`           | The live URL of the details panel off the form fields (pagename/urlPrefix/subdomain) + copying it to the clipboard                                                                                                                                                                |
| `usePublishPageVersions.ts`         | The versions of a page for the details panel: the list of summaries (`loadVersions`) + a preview of a snapshot (`previewVersion`)                                                                                                                                                 |
| `usePublishPreview.ts`              | The preview of a landing or a version: a snapshot in localStorage (`bricks-preview-page`) + opening `<previewPrefix>/<address>`                                                                                                                                                   |
| `usePublishVersionRestore.ts`       | The confirm flow of a rollback to a version: the state of the confirmation modal + the call of the store's `restorePageVersion`                                                                                                                                                   |
| `usePublishPageDelete.ts`           | The confirm flow of deleting a page: the state of the confirmation, the description carrying the address, the call of the store's `deletePage`                                                                                                                                    |
| `useSchemaFileTransfer.ts`          | Moving a schema by file: downloading the JSON and reading a chosen file with the structure validated                                                                                                                                                                              |
| `usePublishSchemaImport.ts`         | Importing a schema on the dashboard: the confirmation of the replacement, resolving the images, writing the schema with a precondition                                                                                                                                            |
| `usePublishDashboardPreferences.ts` | The dashboard's settings: the dark theme (a class on `body`) and switching the locale of the interface                                                                                                                                                                            |
| `usePublishPageActions.ts`          | The actions of a row and of the details panel that need no confirmation: publishing, duplicating, the preview of a page and of its frame                                                                                                                                          |
| `usePublishTemplatesSurface.ts`     | The templates surface: reading the schema of the source page, preselecting a template in the creation form, the shot for the lightbox                                                                                                                                             |
| `usePublishMediaGallery.ts`         | The gallery modal on the dashboard: the mount latch and the visibility of the OG image picker                                                                                                                                                                                     |
| `usePublishDashboardSections.ts`    | The open section of the dashboard and the search line of that section: routing the input of the one field in the header across four lists, putting out the vanished accounts section, resetting the media library session on leaving it                                           |
| `usePublishMediaSurface.ts`         | The media library surface on the dashboard: the upload parameters and progress, the selected file, its edits, its deletion and the full-screen view                                                                                                                               |
| `usePublishDeviceSet.ts`            | The draft of a page's device set for the "Page devices" modal: the inheritance toggle, the checks of the width and the label against the rules of the layout, the re-sorting by width (the key does not change with it), the list of the catalog's devices still available to add |
