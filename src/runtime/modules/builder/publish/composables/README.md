# builder/publish/composables

| Файл                                | Назначение                                                                                                                                                                                                                                        |
| ----------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `usePublishDashboard.ts`            | Состояние дашборда страниц: поиск с debounce, сегмент-фильтр, счётчики фильтров                                                                                                                                                                   |
| `usePublishPagesData.ts`            | Загрузка списка страниц в стор на SSR (`useAsyncData`) + клиентский повтор после отказа сервера                                                                                                                                                   |
| `usePublishPageForm.ts`             | Локальная форма meta панели деталей: vee-validate + общая схема, dirty-детект, сохранение через `patchPage`                                                                                                                                       |
| `usePublishCreatePageForm.ts`       | Форма модалки создания страницы: авто-slugify от названия, общая схема, создание через `createPage` store'а                                                                                                                                       |
| `usePublishDetailsUrl.ts`           | Live-URL панели деталей от полей формы (pagename/urlPrefix/subdomain) + копирование в буфер обмена                                                                                                                                                |
| `usePublishPageVersions.ts`         | Версии страницы для панели деталей: список сводок (`loadVersions`) + превью снапшота (`previewVersion`)                                                                                                                                           |
| `usePublishPreview.ts`              | Превью лендинга/версии: снапшот в localStorage (`bricks-preview-page`) + открытие `<previewPrefix>/<адрес>`                                                                                                                                       |
| `usePublishVersionRestore.ts`       | Confirm-флоу отката к версии: состояние модалки подтверждения + вызов `restorePageVersion` стора                                                                                                                                                  |
| `usePublishPageDelete.ts`           | Confirm-флоу удаления страницы: состояние подтверждения, описание с адресом, вызов `deletePage` стора                                                                                                                                             |
| `useSchemaFileTransfer.ts`          | Перенос схемы файлом: скачивание JSON и чтение выбранного файла с валидацией структуры                                                                                                                                                            |
| `usePublishSchemaImport.ts`         | Импорт схемы на дашборде: подтверждение замены, резолвинг картинок, запись схемы с precondition                                                                                                                                                   |
| `usePublishDashboardPreferences.ts` | Настройки дашборда: тёмная тема (класс `body`) и переключение локали интерфейса                                                                                                                                                                   |
| `usePublishPageActions.ts`          | Действия строки и панели деталей без подтверждения: публикация, дублирование, превью страницы и её кадра                                                                                                                                          |
| `usePublishTemplatesSurface.ts`     | Поверхность шаблонов: чтение схемы страницы-источника, предвыбор шаблона формы создания, снимок для лайтбокса                                                                                                                                     |
| `usePublishMediaGallery.ts`         | Модалка галереи на дашборде: латч монтирования и видимость пикера OG-изображения                                                                                                                                                                  |
| `usePublishDashboardSections.ts`    | Открытый раздел дашборда и строка поиска этого раздела: маршрутизация ввода одного поля шапки по четырём спискам, гашение исчезнувшего раздела учёток, сброс сессии медиатеки при уходе с неё                                                     |
| `usePublishMediaSurface.ts`         | Поверхность медиатеки на дашборде: параметры и прогресс загрузки, выбранный файл, его правки, удаление и полноэкранный просмотр                                                                                                                   |
| `usePublishDeviceSet.ts`            | Черновик набора устройств страницы для модалки «Устройства страницы»: тумблер наследования, проверки ширины и названия по правилам макета, пересортировка по ширине (ключ при этом не меняется), список доступных к добавлению устройств каталога |
