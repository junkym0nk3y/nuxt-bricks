# builder/publish/utils

| Файл                    | Назначение                                                                                                                                                                                                                        |
| ----------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `activeWrites.ts`       | Реестр незавершённых операций записи лендинга: выдача id, закрытие своей операции; запрет второй записи не зависит от отрисовки `disabled`                                                                                        |
| `currentPageWrite.ts`   | Оркестрация записывающих действий стора: `publishPage` (создание + синхронизация списка), `publishCurrentPage` и `saveCurrentPageAsCopy`; в общее состояние формы пишут только по согласию инициатора (DI, тестируется без Pinia) |
| `dates.ts`              | Формат дат дашборда (`formatPageDate` → DD.MM.YYYY, `formatPageDateTime` → + HH:mm, `formatPageVersionDateTime` → дата сохранённой версии)                                                                                        |
| `draftSnapshots.ts`     | Сравнение снапшотов черновика (`isSnapshotEqual`, `isFormStateEqual`)                                                                                                                                                             |
| `draftStorage.ts`       | Черновики билдера в localStorage: адресные ключи (`…:draft:blog/post`), чтение/запись/перенос со статусом исхода, проба доступности хранилища                                                                                     |
| `formState.ts`          | Дефолтное/нормализованное состояние формы публикации, кэш цвета фона из app config                                                                                                                                                |
| `formValidation.ts`     | Валидация формы публикации (`validatePublishFormState`) — обязательные поля, форматы, роутинг, занятость адреса страницы (пара `urlPrefix + pagename`) и адреса её редактора                                                      |
| `keywords.ts`           | Граница «список тегов ↔ строка `keywords`»: `parseKeywords` (split, trim, дедуп) и `serializeKeywords`                                                                                                                            |
| `pageLibraryWrite.ts`   | Запись страниц вне сессии редактора: создание черновика с заданной схемой, дублирование по id (DI, тестируется без Pinia)                                                                                                         |
| `pagesLoad.ts`          | Однократная загрузка полного списка страниц: отличает «не загружали» от «загружено, пусто», сводит параллельных читателей в один запрос, повторяет вытесненный ответ                                                              |
| `pagePayload.ts`        | Сборка payload создания/обновления/PATCH meta страницы (camelCase, snake_case — на вызове)                                                                                                                                        |
| `pageVersionRestore.ts` | Оркестрация `restorePageVersion` стора: обязательный revision-precondition, синхронизация списка, `toPageWriteError` на конфликт (DI, тестируется без Pinia)                                                                      |
| `publishApi.ts`         | API-слой publish-стора: CRUD-запросы `/api/bricks` (+ версии страниц) + нормализация ответов                                                                                                                                      |
| `requestErrors.ts`      | Ошибки запросов: `RequestError` (статус + код конфликта), детект 409-конфликта revision, `requirePageRevision` (precondition отката), `toPageWriteError` (конфликт → refetch списка + локализованный текст)                       |
| `slugify.ts`            | Генерация pagename из названия страницы (`slugifyPageTitle`) — транслитерация, `[a-z0-9-]`; `generateCopyPagename` подбирает свободное имя копии в пределах её префикса                                                           |
| `validationSchema.ts`   | Чистая фабрика yup-схемы meta-полей (`createPublishValidationSchema`) — сайдбар + панель деталей                                                                                                                                  |
| `deviceImpact.ts`       | `countDeviceOverrides` — сколько переопределений исчезнет при удалении устройства (значений, а не блоков: так обещает подтверждение); `describeAbsorbedRange` — какому соседу достанется освободившийся диапазон                  |
