# Страницы и шаблоны

Все страницы проекта собраны в разделе **Страницы** — это стартовый экран билдера. Там же, в соседнем разделе, лежат шаблоны: заготовки, из которых создаются новые страницы.

## Список страниц

![Список страниц](./images/dashboard-pages.webp)

- Фильтры **Все**, **Опубликованные** и **Черновики** показывают число страниц в каждой группе.
- Поле **Поиск страниц** в шапке ищет по названию, адресу и описанию.
- **Обновить список** подтягивает изменения, сделанные коллегами, без перезагрузки страницы.
- Зелёная точка у строки — страница опубликована. Серая точка и метка «Черновик» — посетители её не видят.
- Щелчок по миниатюре открывает снимок страницы в полный размер.

При наведении на строку справа появляются кнопки:

| Кнопка                   | Что делает                                                      |
| ------------------------ | --------------------------------------------------------------- |
| **Редактировать**        | Открывает страницу в редакторе                                  |
| **Превью**               | Открывает сохранённую страницу в новой вкладке                  |
| **Дублировать**          | Создаёт копию-черновик с адресом вида `vesna-copy`              |
| **Сохранить как шаблон** | Сохраняет страницу шаблоном, подробнее — [ниже](#шаблоны)       |
| **Удалить**              | Удаляет страницу после подтверждения. Только для администратора |

## Детали страницы

Щелчок по строке открывает справа панель страницы.

![Панель страницы](./images/dashboard-details.webp)

Сверху стоит переключатель **Опубликована**. Он срабатывает сразу, без отдельного сохранения. У опубликованной страницы под ним видна её ссылка с кнопкой копирования.

Ниже идут те же поля, что и в настройках редактора: **SEO и Meta**, **Код страницы**, **OG-изображение** и **Маршрутизация** с префиксом URL и субдоменом. Все они описаны в статье [Настройки и публикация](./08-publishing.md). Когда вы меняете поле, внизу панели появляются кнопки **Сохранить изменения** и **Отменить**.

Внизу панели есть кнопки **Открыть в редакторе**, **Дублировать** и корзина для удаления.

### Версии

При каждом сохранении содержимого страницы билдер откладывает снимок предыдущего состояния. Блок **Версии** в панели страницы показывает эти снимки с датами. Первой идёт текущая версия.

![Версии и схема страницы](./images/page-versions.webp)

При наведении на снимок появляются две кнопки:

- **Превью** — открывает эту версию в новой вкладке;
- **Восстановить** — возвращает страницу к этой версии. Билдер переспросит, а текущее состояние уйдёт в историю, так что восстановление тоже можно откатить.

Версия хранит блоки и их настройки. Адрес, SEO, статус публикации, код страницы и флажок noindex при восстановлении не меняются.

Сколько версий хранить, задаёт проект, по умолчанию — пять последних.

### Схема: экспорт и импорт

Блок **Схема** в самом низу панели переносит содержимое страницы файлом:

- **Экспорт JSON** скачивает блоки страницы и их настройки одним файлом. Подходит для резервной копии или переноса в другой проект.
- **Импорт JSON** заменяет содержимое страницы схемой из файла. Билдер переспросит, а прежнее состояние останется в версиях.

## Создание страницы

Кнопка **+ Создать страницу** в шапке открывает окно **Новая страница**.

![Окно создания страницы](./images/create-page.webp)

1. **Название страницы** — заголовок, который увидят в списке и во вкладке браузера.
2. **Адрес (pagename)** — собирается из названия сам, его можно поправить. Под полем видно, по какому адресу откроется страница.
3. **Описание (description)** — короткий текст для поисковой выдачи.
4. **Начать с** — откуда взять содержимое:
    - **Пустая страница** — чистый канвас;
    - **Из шаблона** — копия сохранённого шаблона, выбирается из списка;
    - **Из JSON-файла** — схема, выгруженная раньше через **Экспорт JSON**.
5. **Дополнительно** — префикс URL, субдомен, ключевые слова и набор устройств. Их можно задать и позже.

**Создать и открыть в редакторе** создаёт страницу черновиком и сразу открывает редактор.

## Шаблоны

Шаблон — это заготовка страницы: блоки и оформление, сохранённые под своим именем. Страница из шаблона с ним не связана: правка или удаление шаблона ничего не меняют в уже созданных страницах.

![Раздел «Шаблоны»](./images/templates.webp)

### Сохранить шаблон

Шаблон делается из готовой страницы двумя способами:

- в списке страниц — кнопка **Сохранить как шаблон** в строке;
- в редакторе — пункт **Сохранить как шаблон** в меню кнопки **Сохранить**.

Разница в том, что попадает в шаблон. Из списка уходит сохранённая версия страницы, а из редактора — то, что сейчас на канвасе, вместе с несохранёнными правками. Миниатюрой в обоих случаях станет снимок последнего сохранения, поэтому у ни разу не сохранённой страницы шаблон будет без картинки.

![Окно «Сохранить как шаблон»](./images/save-template.webp)

В окне задайте **Название шаблона** и, если нужно, **Описание**. Два шаблона с одинаковым названием завести нельзя.

| Попадает в шаблон                                 | Остаётся у страницы                                      |
| ------------------------------------------------- | -------------------------------------------------------- |
| Блоки и их настройки                              | Адрес: pagename, префикс URL, субдомен                   |
| Оформление: раскладка, цвет фона, набор устройств | SEO: заголовок, описание, ключевые слова, OG-изображение |
| Миниатюра — снимок страницы                       | Статус публикации и версии                               |

### Создать страницу из шаблона

Наведите курсор на карточку шаблона и нажмите **Создать страницу**. Откроется обычное окно создания, где уже выбран этот шаблон. Тот же путь есть в окне **+ Создать страницу**: вариант **Из шаблона**.

Адрес, описание и SEO новая страница берёт из окна создания, а не из шаблона. Иначе две страницы из одного шаблона претендовали бы на один адрес.

### Править и удалять

На карточке шаблона есть кнопки **Посмотреть** (снимок в полный размер), **Изменить название и описание** и **Удалить шаблон**. Удалять шаблоны может только администратор.

Содержимое шаблона не редактируется. Чтобы обновить заготовку, сохраните новый шаблон из нужной страницы и удалите прежний.
