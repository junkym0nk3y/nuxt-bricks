# Работа с блоками

Страница собирается из блоков двух видов:

- **Layout-блоки** — встроенные контейнеры и простые элементы: Section, Grid, Flex, Slider, Space, Text, Media, Svg, Accordion. Они есть в любом проекте и описаны в статье [Layout-блоки](./04-layouts.md).
- **Компоненты проекта** — блоки, которые разработчики сделали для вашего сайта: баннеры, карточки, формы. Набор компонентов и их свойства у каждого проекта свои.

## Библиотека

Библиотека открывается кнопкой **Компоненты** в левом рейле.

![Библиотека компонентов](./images/component-library.webp)

- Блоки сгруппированы по категориям. **Layout** — встроенные блоки, остальные категории задаёт проект.
- Поле **Поиск компонентов** фильтрует блоки по названию.
- Звёздочка рядом с поиском оставляет **Только избранные**. В избранное блок добавляется из его [контекстного меню](#контекстное-меню). Избранное хранится в браузере и на другом компьютере будет своё.
- Значок «i» на карточке показывает короткое описание блока.

## Добавление блока

Перетащите карточку из библиотеки на канвас. Пока вы ведёте блок, подсказка показывает, куда он встанет. Чтобы вложить блок в контейнер, отпустите его над контейнером: подсветится зона, куда он попадёт.

Готовые блоки на канвасе тоже перетаскиваются: так меняется их порядок и вложенность. То же самое можно сделать в панели [Схема](./02-interface.md).

## Панель свойств

Щелчок по блоку открывает справа панель его свойств. В шапке — имя блока, значок «i» рядом с ним показывает описание. Ниже идут вкладки **Устройство**: на вкладке базового, самого широкого устройства правятся все свойства, на остальных — только адаптивные. Как это работает, рассказано в статье [Адаптивность](./06-adaptive.md).

### Отображение

| Поле                           | Что делает                                                                                        |
| ------------------------------ | ------------------------------------------------------------------------------------------------- |
| **Отображать компонент**       | Выключает блок целиком: он остаётся в схеме, но не попадает на страницу                           |
| **Показывать на**              | Галочки устройств набора. Снимите галочку, чтобы скрыть блок на этом устройстве                   |
| **Отображать на всю страницу** | Растягивает блок на всю ширину страницы, мимо боковых полей. Есть только у блоков верхнего уровня |
| **HTML ID**                    | Идентификатор для якорных ссылок. Блок с ID `faq` откроется по ссылке `#faq`                      |

Отключённый блок на канвасе помечен надписью «Отключен», в схеме — значком глаза.

### Свойства

Набор полей зависит от блока. Связанные поля собраны в сворачиваемые группы, например «Фон», «Отступы», «Размеры». Щелчок по заголовку группы сворачивает её. Внизу панели есть кнопка **Удалить**.

| Поле                  | Как работает                                                                           |
| --------------------- | -------------------------------------------------------------------------------------- |
| Число                 | Ввод с кнопками **+** и **−**. Рядом подписана единица, например `rem`                 |
| Текст                 | Обычное поле ввода                                                                     |
| Список                | Выбор одного варианта                                                                  |
| Флажок                | Включает или выключает опцию                                                           |
| Цвет                  | Образец с палитрой и поле для кода: `#1F2A44` или CSS-переменная `var(--…)`            |
| Медиа                 | Превью файла и кнопки **Выбрать** (открывает [медиатеку](./05-media.md)) и **Удалить** |
| Отступы               | Схема блока с числами сверху, снизу и по бокам                                         |
| Размер сетки          | Поле из ячеек: щелчок по ячейке задаёт число колонок и строк                           |
| Форматированный текст | Редактор с панелью форматирования, описан ниже                                         |
| Элементы аккордеона   | Список пунктов «заголовок и содержимое»: добавить, переставить, удалить                |

У компонентов проекта встречаются и другие поля: галерея изображений с подписями и тегами, inline-контент (заголовок из сегментов текста, переносов и картинок), редактор JSON с кнопкой **Форматировать**.

В редакторе отступов боковое поле задаётся слева, а справа повторяется зеркально.

![Редактор отступов](./images/spacing-box.webp)

## Контекстное меню

Правый щелчок по блоку на канвасе открывает меню действий. Сочетания клавиш в нём подписаны.

![Контекстное меню блока](./images/context-menu.webp)

| Пункт                          | Что делает                                                                                      |
| ------------------------------ | ----------------------------------------------------------------------------------------------- |
| **Редактировать**              | Выделяет блок и открывает панель свойств                                                        |
| **Копировать**                 | Кладёт блок со всем содержимым в буфер билдера                                                  |
| **Вставить**                   | Ставит копию из буфера туда, где стоял скопированный блок                                       |
| **Дублировать**                | Сразу создаёт копию блока рядом с ним                                                           |
| **Удалить**                    | Удаляет блок                                                                                    |
| **Переместить вверх / вниз**   | Сдвигает блок на одно место среди соседей                                                       |
| **В избранное**                | Отмечает блок этого типа звёздочкой в библиотеке                                                |
| **Интерактивный предпросмотр** | Оживляет блок на канвасе: работают клики, слайдер, аккордеон. Повторный выбор возвращает правку |
| **Отключить / Включить**       | То же, что флажок **Отображать компонент**                                                      |
| **Видимость на устройствах**   | Подменю с галочками устройств, то же, что **Показывать на**                                     |

Действия, которые меняют страницу, отменяются кнопкой «шаг назад» под канвасом или `Ctrl/⌘ + Z`. Копирование, избранное и интерактивный предпросмотр страницу не меняют и в историю действий не попадают.

## Редактирование текста

Текст блока Text и другие поля с форматированием правятся тремя способами: прямо на канвасе, в панели свойств и в большом окне.

### На канвасе

Дважды щёлкните по тексту. Над блоком появится плавающая панель форматирования. Её можно перетащить за верхний край и растянуть за угол. Правки сразу попадают в панель свойств. Закончить можно кнопкой **Готово** или клавишей `Escape`.

![Редактирование текста на канвасе](./images/inline-editing.webp)

### Панель форматирования

| Кнопки         | Что делают                                                                   |
| -------------- | ---------------------------------------------------------------------------- |
| **B**, _I_, U  | Жирный, курсив, подчёркивание                                                |
| Ссылка         | Адрес, «Открывать в новой вкладке» и **Убрать ссылку**                       |
| Шрифт и размер | Семейство шрифта из набора проекта и размер в `rem`                          |
| Интервалы      | Толщина шрифта, межстрочный (`1.35`, `120%`, `2rem`) и межбуквенный интервал |
| Цвет текста    | Палитра и поле для кода цвета                                                |
| Выравнивание   | По левому краю, по центру, по правому краю, по ширине                        |
| Списки         | Маркированный и нумерованный                                                 |
| Разделитель    | Горизонтальная линия                                                         |
| Изображение    | Вставка картинки из медиатеки                                                |

Ссылка без протокола получает `https://`. Ещё допустимы `mailto:`, `tel:`, якорь `#…` и путь от корня сайта `/…`.

### В панели свойств и в большом окне

В панели свойств над текстом есть переключатель **Код**: он показывает HTML-разметку вместо визуального вида. При наведении на поле в его углу появляется кнопка **Развернуть**, которая открывает окно **Редактор текста** с тем же набором инструментов и большой рабочей областью.

![Текстовое поле в панели свойств](./images/text-panel.webp)

![Окно «Редактор текста»](./images/text-editor-modal.webp)

Кнопка **Тёмный фон** в углу поля меняет только фон предпросмотра, текст не трогает. Она нужна, когда светлый текст лежит на тёмной секции и на белом фоне его не видно.

### Картинки в тексте

Кнопка вставки изображения открывает [медиатеку](./05-media.md). Вставленную картинку можно:

- **растянуть** за угловые маркеры. Пропорции по умолчанию сохраняются, этот режим отключается переключателем «Пропорции сохраняются»;
- **выровнять по строке**: по базовой линии, по центру, по верху или по низу;
- **обтекать текстом**: «Обтекание слева», «Обтекание справа» или «Без обтекания».
