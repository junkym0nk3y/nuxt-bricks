# Работа с компонентами

Компоненты — основные строительные блоки лендинга. Это готовые элементы интерфейса: баннеры, карточки, заголовки, формы и другие блоки. Каждый компонент имеет свой набор настраиваемых свойств.

## Категории компонентов

Компоненты разделены на категории для удобного поиска. Откройте библиотеку компонентов — нажмите кнопку **Компоненты** в левой панели.

![Библиотека компонентов](./images/component-library.png)

Категории зависят от проекта. Типичные: **Layout**, **Buttons**, **Cards**, **Gallery**, **Sections**. В категории Layout находятся контейнерные компоненты: Grid, Flex, Space, Slider, Text, Media, Accordion.

Помимо обычных компонентов, существуют **layout-контейнеры** — специальные блоки для группировки и расположения других элементов. Подробнее о них — в статье [Layout-контейнеры](./04-layouts.md).

В библиотеке есть поиск по названию и кнопка избранного для быстрого доступа к часто используемым блокам.

![Поиск и избранное](./images/favorites-filter.png)

### Избранные компоненты

Нажмите звёздочку рядом с полем поиска, чтобы отфильтровать только избранные компоненты. Добавить компонент в избранное можно через панель инструментов — нажмите звёздочку на тулбаре выделенного блока (подробнее в разделе [Панель инструментов компонента](#панель-инструментов-компонента)). Избранное сохраняется между сессиями.

## Добавление на канвас

1. Откройте библиотеку компонентов.
2. Найдите нужный блок в списке или воспользуйтесь поиском.
3. Перетащите его на канвас — зажмите блок мышью и отпустите в нужном месте на полотне.

Блок появится на канвасе и будет готов к настройке.

## Панель свойств

Нажмите на блок на канвасе — слева откроется панель свойств.

![Панель свойств](./images/properties-panel.png)

### Секция «Отображение»

В верхней части панели находятся общие параметры:

- **Отображать компонент** — включает или полностью выключает блок. Используйте, если блок ещё в работе и вы не хотите, чтобы он показывался.
- **Показывать на** — управляет видимостью блока на конкретном устройстве; в списке устройства набора страницы. Подробнее — в статье [Адаптивность](./06-adaptive.md).
- **Отображать на всю страницу** — растягивает блок на всю ширину, игнорируя стандартную сетку. Часто используется для баннеров и заголовков.
- **HTML ID** — произвольный идентификатор для элемента (например, `my-section`). Можно использовать для якорных ссылок.

### Секция «Свойства»

Ниже расположены свойства, специфичные для конкретного компонента. Набор полей зависит от типа блока.

#### Группы свойств

Некоторые компоненты организуют свойства в **сворачиваемые группы**. Например, у секции свойства разделены на группы «Фон» и «Отступы», а у Space — группа «Разделитель».

Нажмите на заголовок группы, чтобы свернуть или развернуть её. По умолчанию все группы открыты. Свойства, не входящие в группу, отображаются над группами в обычном плоском списке.

## Типы полей

| Тип поля            | Описание                                                                                           |
| ------------------- | -------------------------------------------------------------------------------------------------- |
| Текстовое поле      | Ввод текста или числа                                                                              |
| Многострочное поле  | Текст с форматированием (жирный, курсив, подчёркивание, списки, выравнивание, цвет, шрифт, размер) |
| Inline-контент      | Редактор сегментов для заголовков: текст, переносы строк и медиа-элементы                          |
| Выпадающий список   | Выбор одного варианта из нескольких                                                                |
| Переключатель       | Включение или выключение опции                                                                     |
| Изображение         | Выбор картинки из [медиагалереи](./05-media.md)                                                    |
| Видео               | Выбор видеофайла из медиагалереи                                                                   |
| Цвет                | Выбор цвета через палитру                                                                          |
| Галерея изображений | Набор картинок с возможностью сортировки перетаскиванием                                           |
| JSON-редактор       | Редактирование сложных данных (массивы, объекты)                                                   |
| Выбор модалки       | Выпадающий список с доступными модальными окнами                                                   |

### Многострочное поле (textarea)

Для полей с форматированием доступна панель инструментов:

- Кнопки **B** / _I_ / U — жирный, курсив, подчёркивание.
- Выбор шрифта, размера, межстрочного интервала и кернинга. Для интервалов можно вводить значения в **rem** или **%** (например, `120%` для line-height или `5%` для letter-spacing).
- Цвет текста.
- Выравнивание (лево, центр, право, по ширине).
- Маркированный и нумерованный списки.
- Добавление изображений
- Добавление таблиц
- Кнопка **Код** — переключает между визуальным режимом и редактированием HTML-кода.

Все изменения применяются мгновенно — вы сразу видите результат на канвасе.

## Панель инструментов компонента

При выделении блока на канвасе справа от него появляется плавающая панель инструментов.

![Панель инструментов](./images/canvas-item-toolbar.png)

По умолчанию панель свёрнута и показывает только название компонента. Нажмите на название, чтобы раскрыть полный набор кнопок:

| Кнопка                  | Что делает                                                                  |
| ----------------------- | --------------------------------------------------------------------------- |
| **Название** (Text >)   | Сворачивает / разворачивает панель                                          |
| **Звёздочка**           | Добавляет блок в избранное — он появится при фильтрации в библиотеке        |
| **Интерактивный режим** | Включает просмотр взаимодействий (клики, модалки) без режима редактирования |
| **Копировать**          | Дублирует блок на канвасе                                                   |
| **Удалить**             | Удаляет блок                                                                |
| **Видимость**           | Скрывает блок; выпадающий список позволяет задать видимость по устройствам  |
| **Вверх / Вниз**        | Перемещает блок вверх или вниз по оси Z (порядок наложения)                 |

## Копирование, удаление, перемещение

- **Копировать блок**: выделите его и нажмите `Ctrl/Cmd + C`, затем `Ctrl/Cmd + V`.
- **Удалить блок**: выделите его и нажмите `Delete` или `Backspace`, либо используйте кнопку **Удалить** внизу панели свойств.
- **Переместить блок**: перетащите его вверх или вниз на канвасе. Также можно использовать вкладку [Схема](./02-interface.md) для навигации по блокам.

## Редактирование текста прямо на канвасе

Блок **Text** поддерживает редактирование прямо на полотне — без перехода в панель свойств.

![Inline-редактирование](./images/inline-editing.png)

1. **Дважды нажмите** на текстовый блок на канвасе.
2. Над блоком появится тулбар с надписью «Инлайн редактор» и кнопками **Готово** / **Esc — выйти**.
3. Редактируйте текст прямо в блоке.
4. Чтобы завершить — нажмите кнопку **Готово** или клавишу `Escape`.

### Особенности inline-редактирования

Не все компоненты поддерживают редактирование подобным образом, но везде, где доступен HTML-контент внутри компонента, есть возможность:

- Использовать полное форматирование: жирный, курсив, списки и другие стили.
- Добавлять изображения прямо в текст.
- Изменения на канвасе автоматически синхронизируются с панелью свойств — и наоборот.

### Работа с изображениями в тексте

В тулбаре инлайн-редактора (а также в панели свойств для многострочных полей) есть кнопка вставки изображения. При нажатии откроется [медиагалерея](./05-media.md), где можно выбрать нужную картинку.

После вставки изображение можно:

- **Масштабировать** — потяните за угловые маркеры, чтобы изменить размер. Пропорции сохраняются автоматически.
- **Настроить обтекание текстом** — при выделении изображения над ним появляется всплывающая панель с тремя режимами:

| Режим                | Описание                                                         |
| -------------------- | ---------------------------------------------------------------- |
| **Обтекание слева**  | Изображение прижимается к левому краю, текст обтекает его справа |
| **Обтекание справа** | Изображение прижимается к правому краю, текст обтекает его слева |
| **Без обтекания**    | Изображение занимает отдельную строку, текст идёт ниже           |

### Развёрнутый редактор текста

Для более удобной работы с большими текстами можно открыть полноэкранный редактор. Наведите курсор на текстовую область в панели свойств — в правом верхнем углу появится кнопка развёртывания.

![Кнопка развёртывания](./images/textarea-expand-button.png)

Нажмите на неё — откроется модальное окно **«Редактор текста»** с расширенным тулбаром.

![Редактор текста](./images/text-editor-modal.png)

Редактор текста предоставляет:

- Полный набор инструментов форматирования (как в панели свойств).
- Переключатель **Код** — для просмотра и редактирования HTML-разметки напрямую.
- Большую рабочую область без ограничений по высоте.
- Кнопку **Готово** для сохранения и закрытия.

Все изменения, сделанные в развёрнутом редакторе, мгновенно синхронизируются с канвасом и панелью свойств.
