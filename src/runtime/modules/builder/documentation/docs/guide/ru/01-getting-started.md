# Начало работы

Конструктор лендингов позволяет собирать посадочные страницы из готовых блоков без написания кода. Вы перетаскиваете компоненты на полотно, настраиваете их свойства и публикуете результат.

## Менеджер страниц

Перейдите по адресу `/bricks` в браузере — откроется менеджер страниц. Это единый центр управления: здесь живёт список всех страниц с поиском и фильтрами (Все / Опубликованные / Черновики), панель деталей с настройками выбранной страницы и кнопка создания новой.

В левом рейле доступны разделы **Страницы** и **Шаблоны**, а также **Media** (медиагалерея), **Документация**, переключатель тёмной темы и языка интерфейса.

## Первые шаги

1. Нажмите **+ Создать страницу** в шапке менеджера.
2. Заполните название — URL (slug) сгенерируется автоматически, при необходимости отредактируйте его — и описание. Нажмите **Создать**: откроется пустой редактор.
3. Нажмите **Компоненты** в левой панели — откроется библиотека блоков.
4. Перетащите нужный блок на канвас.
5. Нажмите на блок — в левой панели автоматически откроется вкладка **Свойства**. Настройте содержимое.
6. Нажмите **Сохранить** в верхней панели.

Готово — ваша первая страница создана. Далее вы можете добавлять новые блоки, настраивать их расположение с помощью [layout-контейнеров](./04-layouts.md) и проверять, как страница выглядит на разных устройствах (см. [Адаптивность](./06-adaptive.md)). Остальные параметры страницы (URL, meta-описание, публикация) можно править как в редакторе — вкладка **Настройки**, — так и в панели деталей менеджера страниц (подробнее — в статье [Сохранение и публикация](./07-publishing.md)).

## Обзор интерфейса редактора

![Обзор интерфейса билдера](./images/builder-overview.png)

Интерфейс состоит из трёх основных зон:

- **Верхняя панель** — кнопки управления: сетка, отмена/повтор, менеджер страниц, медиагалерея, превью и сохранение.
- **Левая панель** — четыре вкладки: Компоненты, Свойства, Схема и Настройки.
- **Канвас** — основная рабочая область, куда перетаскиваются блоки.

Подробнее о каждой зоне — в статье [Интерфейс билдера](./02-interface.md).
