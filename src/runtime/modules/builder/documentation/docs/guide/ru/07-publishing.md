# Сохранение и публикация

После сборки лендинга вы можете сохранить его как черновик, посмотреть превью или опубликовать для посетителей сайта.

## Настройки страницы

Перед сохранением заполните настройки страницы — откройте вкладку **Настройки** в левой панели.

![Настройки страницы](./images/page-settings.png)

| Поле                 | Описание                                                                                                                                                                      | Обязательное |
| -------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :----------: |
| **Layout**           | Шаблон раскладки страницы (например, `default`)                                                                                                                               |     Нет      |
| **URL**              | Адрес страницы на сайте (например, `promo-2024`)                                                                                                                              |      Да      |
| **URL Prefix**       | Префикс пути перед URL страницы (например, `blog`). Допускает вложенность через `/` (например, `blog/news`). Только строчные латинские буквы, цифры и дефисы. До 100 символов |     Нет      |
| **Субдомен**         | Привязка страницы к поддомену (например, `spb`). Страница будет доступна только с указанного поддомена. Только строчные латинские буквы, цифры и дефисы. До 63 символов       |     Нет      |
| **Название**         | Заголовок страницы для поисковых систем                                                                                                                                       |      Да      |
| **Meta Description** | Описание страницы (до 500 символов)                                                                                                                                           |      Да      |
| **Meta Keywords**    | Ключевые слова для SEO                                                                                                                                                        |     Нет      |
| **OG/Twitter image** | Изображение для предпросмотра в соцсетях (выбирается из медиагалереи)                                                                                                         |     Нет      |
| **Цвет фона**        | Цвет фона лендинга (hex-код, например `#FFFFFF`)                                                                                                                              |     Нет      |

> Если обязательные поля не заполнены, рядом с вкладкой «Настройки» в левой панели появится красная точка-индикатор.

### URL Prefix и Субдомен

Эти поля влияют на итоговый адрес опубликованной страницы. Под полями ввода отображается превью финального URL.

**Примеры формирования адреса:**

| URL     | URL Prefix  | Субдомен | Итоговый адрес                |
| ------- | ----------- | -------- | ----------------------------- |
| `promo` | —           | —        | `example.com/promo`           |
| `promo` | `blog`      | —        | `example.com/blog/promo`      |
| `promo` | `blog/news` | —        | `example.com/blog/news/promo` |
| `promo` | —           | `spb`    | `spb.example.com/promo`       |
| `promo` | `blog`      | `spb`    | `spb.example.com/blog/promo`  |

> **Важно:** если указан субдомен, страница будет доступна **только** при обращении с соответствующего поддомена. При обращении с другого домена вернётся ошибка 404. В режиме превью проверка субдомена не выполняется.

### Экспорт и импорт схемы

В нижней части настроек находятся кнопки для работы со схемой страницы:

- **Экспорт JSON** — сохраняет текущую структуру страницы в JSON-файл. Удобно для резервного копирования или переноса между проектами.
- **Импорт JSON** — загружает ранее сохранённую схему. Текущее содержимое канваса будет заменено данными из файла.

## Сохранение

Нажмите кнопку **Сохранить** в правой части верхней панели. Доступны два варианта:

- **Сохранить изменения** — обновляет текущую страницу в базе.
- **Сохранить как копию** — создаёт новый черновик с тем же содержимым. Исходная страница останется без изменений. Это удобно, когда вы хотите попробовать другой вариант, не теряя текущую версию.

## Превью

Нажмите кнопку **Превью** в верхней панели — страница откроется в новой вкладке браузера. Превью работает даже с несохранёнными изменениями: оно берёт актуальные данные прямо из редактора.

При активном превью изменения в билдере автоматически синхронизируются с вкладкой превью в реальном времени — вы сразу видите результат без перезагрузки.

## Менеджер страниц

Список всех сохранённых страниц открывается по названию страницы в верхней панели — пункт **Все страницы** внизу выпадающего списка. Туда же ведёт прямой адрес `/bricks`.

![Менеджер страниц](./images/page-editor.png)

Для каждой страницы отображаются:

- **Название** и URL страницы.
- **Описание** (meta description).
- **Дата последнего обновления.**
- **Переключатель публикации** — включает или выключает доступ к странице по публичному URL.

В этом окне вы можете:

- **Превью** — открыть предпросмотр сохранённой страницы.
- **Редактировать** — перейти к редактированию страницы в билдере.
- **Удалить** — удалить страницу из базы.

Опубликованные страницы доступны по своему адресу `/<url-страницы>` (с учётом URL-префикса и субдомена — см. таблицу выше).

## Управление публикацией

Для публикации или снятия с публикации используйте переключатель в списке страниц:

- **Включён** (синий) — страница доступна посетителям.
- **Выключен** (серый) — страница недоступна для посетителей, видна только в редакторе.

**Совет:** заполните настройки SEO (URL, название, описание) в самом начале работы — до того, как начнёте добавлять блоки. Это поможет не забыть про них перед публикацией.

## Восстановление несохранённых изменений

Билдер автоматически сохраняет черновик ваших изменений в фоновом режиме. Если вы закроете браузер или случайно уйдёте со страницы — данные не будут потеряны.

### Как это работает

Каждые несколько секунд билдер записывает текущее состояние канваса и настроек в локальное хранилище браузера. Этот процесс полностью автоматический и не требует никаких действий.

### Восстановление черновика

При открытии ранее сохранённой страницы билдер проверяет, есть ли для неё незавершённые изменения. Если черновик найден — появится диалоговое окно:

![Восстановление изменений](./images/confirm-action-modal.png)

| Кнопка                     | Что произойдёт                                                                |
| -------------------------- | ----------------------------------------------------------------------------- |
| **Восстановить изменения** | Черновик будет загружен — вы продолжите работу с того места, где остановились |
| **Открыть сохранённую**    | Черновик будет удалён, откроется последняя сохранённая версия страницы        |

### Для новых страниц

Если вы работали над новой (ещё не сохранённой) страницей, при повторном открытии билдера черновик загрузится автоматически — без дополнительного запроса. В нижней части экрана появится красное уведомление «Есть несохранённые изменения».

### Когда черновик удаляется

Черновик удаляется автоматически в двух случаях:

- После успешного сохранения или публикации страницы.
- Если вы откатили все изменения до состояния, идентичного сохранённой версии.
