# Медиагалерея

Медиагалерея — это хранилище изображений и видео, которые вы используете в компонентах лендинга. Загруженные файлы автоматически оптимизируются и становятся доступны во всех блоках, где есть поле для изображения или видео.

## Как открыть галерею

В редакторе страницы — кнопка **Загружаемый контент** в правой части верхней панели. В списке страниц — пункт **Media** в боковой навигации. Галерея одна и та же, содержимое общее для всех страниц проекта.

## Категории

Готового набора категорий нет: все категории заводите вы сами, под свой проект. Пока ни одной не создано, в дорожке над сеткой есть только фильтр **Все**.

- **Создать категорию** — кнопка **+** справа от дорожки. Введите название и нажмите Enter (или галочку). Название — обычный текст на русском или английском, до 50 символов: адрес категории система соберёт из него сама, переводя кириллицу в латиницу. Название целиком из других алфавитов (иероглифы, арабица) не подойдёт — собирать адрес будет не из чего. Категория с таким же названием второй раз не создастся — поле сразу подсветит, что она уже есть.
- **Удалить категорию** — кнопка с карандашом справа от дорожки включает режим управления, и у каждой категории появляется крестик. Перед удалением галерея переспросит и покажет, сколько файлов затронет.
- **Файлы при удалении категории не удаляются** — они остаются в медиатеке и становятся файлами без категории.

Файл может лежать вне категорий — это нормальное состояние, а не ошибка. Такие файлы видны только в фильтре **Все**: в счётчик рядом с названием категории они не попадают, потому что не принадлежат ни одной.

Категорию отдельного файла можно поменять в любой момент: выделите файл и выберите категорию в нижней панели. Там же есть вариант **Без категории** — им категория снимается.

## Поиск

Строка **Поиск** в шапке галереи ищет по имени файла и alt-тексту. Поиск работает вместе с выбранной категорией: сначала фильтр, потом строка.

## Загрузка файлов

Загрузить файлы можно тремя способами:

1. Кнопкой **Загрузить** в шапке галереи.
2. Плиткой **Загрузить файлы** — она стоит первой ячейкой сетки.
3. Перетаскиванием: файлы можно бросить в любое место окна галереи, приёмник развернётся сам.

Можно выбирать сразу несколько файлов — они загрузятся по очереди, а на кнопке будет виден счётчик вида «Загружаю 2 из 5».

**Категорию новые файлы получают от активного фильтра.** Если открыта категория «Промо» — файлы попадут в неё; если открыт фильтр **Все** — файлы сохранятся без категории. Так что перед загрузкой проще выбрать нужную категорию в дорожке, а не переставлять её потом у каждого файла.

Ограничения на размер зависят от настроек проекта; текущие значения показываются в подсказке у кнопки **Загрузить** и в приёмнике при перетаскивании. Принимаются изображения и видео, остальные файлы галерея отклонит с сообщением.

## Параметры оптимизации

Кнопка с шестерёнкой рядом с **Загрузить** открывает параметры, с которыми обрабатываются загружаемые файлы:

| Параметр                      | Что делает                                                                     |
| ----------------------------- | ------------------------------------------------------------------------------ |
| **Формат**                    | `WebP` — конвертировать растровое изображение; `Оригинал` — сохранить как есть |
| **Качество**                  | Степень сжатия при конвертации в WebP                                          |
| **Макс. ширина**              | Потолок ширины: изображение шире — уменьшается, меньше — остаётся как есть     |
| **Загружать без оптимизации** | То же, что формат `Оригинал`: файл сохраняется без обработки                   |

Параметры действуют на следующую загрузку и в настройки проекта не записываются: при повторном открытии галереи в поповере снова будут значения из конфигурации. Кнопки «Применить» нет — поповер просто закрывается кликом снаружи.

Для растровых изображений уменьшенные варианты (превью и совсем маленький mock) создаются всегда — даже при загрузке без оптимизации: без них блоку с изображением нечем показывать постепенную загрузку. Каким именно способом картинка проявляется на опубликованной странице, выбирается у самого блока, а не здесь.

Векторная графика (SVG) и видео этих параметров не касаются: SVG сохраняется как есть, после очистки от небезопасного содержимого, видео — без обработки. Уменьшенных вариантов у них нет, и это норма, а не сбой загрузки.

## Свойства файла

Выделите файл в сетке — в нижней панели откроются его свойства:

- **Имя** — подпись файла в медиатеке; адрес самого файла в хранилище от неё не зависит.
- **Alt** — текстовое описание изображения для поисковиков и скринридеров. У видео поле недоступно: alt применяется только к картинкам.
- **Категория** — выпадающий список заведённых категорий плюс вариант **Без категории**.
- **Корзина** — удаление файла из медиатеки. Действие необратимо, галерея переспросит.

Имя и alt сохраняются, когда вы уходите из поля (кликом мимо или Tab), — отдельной кнопки сохранения нет. Пустое имя не сохраняется: поле вернётся к прежнему значению, потому что у файла в медиатеке всегда должно быть название.

Под полями идёт техническая сводка: размеры в пикселях, вес и формат файла.

Кнопка увеличительного стекла на плитке открывает файл в полноэкранном просмотре.

## Выбор изображения для компонента

1. Выберите блок на канвасе.
2. В панели свойств найдите поле с типом «Изображение».
3. Нажмите кнопку **Выбрать** — откроется медиагалерея.
4. Выделите нужный файл и нажмите **Выбрать** в правом нижнем углу.

Изображение будет привязано к свойству компонента и сразу отобразится на канвасе. Для удаления привязки нажмите **Удалить** рядом с превью.

## Рекомендуемые форматы

| Формат   | Когда использовать                                   |
| -------- | ---------------------------------------------------- |
| **WebP** | Основной формат. Хорошее сжатие при высоком качестве |
| **SVG**  | Иконки, логотипы, простая графика                    |
| **PNG**  | Изображения с прозрачностью                          |

> Растровые изображения по умолчанию оптимизируются и конвертируются в WebP. Отключает это режим **Оригинал** в параметрах загрузки. Анимированные GIF, WebP и AVIF не перекодируются в любом случае — от них остался бы один кадр.
