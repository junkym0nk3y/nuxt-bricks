# Медиатека

Медиатека хранит картинки и видео проекта. Файлы в ней общие для всех страниц: загруженное один раз можно поставить в любой блок с полем для изображения или видео.

## Где открыть

Медиатека открывается двумя путями, а содержимое у них одно и то же:

- в списке страниц — раздел **Медиатека** в левом меню. Свойства выбранного файла показываются в панели справа;
- в редакторе — кнопка **Загружаемый контент** в верхней панели. Откроется окно «Управление медиа-контентом», свойства файла в нём показываются внизу.

![Медиатека в списке страниц](./images/media-library.webp)

## Категории

Готовых категорий нет, их заводит сам проект. Над сеткой файлов идёт строка фильтров: **Все** и созданные категории, у каждой подписано число файлов.

- **Создать категорию.** Нажмите **+** справа от фильтров, введите название и нажмите `Enter`. Название — до 50 символов, по-русски или по-английски: адрес категории соберётся из него сам, кириллица перейдёт в латиницу. Название целиком из других алфавитов, например из иероглифов, не подойдёт. Дубль поле подсветит сразу.
- **Удалить категорию.** Карандаш справа от фильтров включает режим управления, и у категорий появляются крестики. Перед удалением медиатека переспросит и скажет, у скольких файлов не останется категории. Сами файлы не удаляются. Удалять категории может только администратор.

Файл без категории — нормальное состояние. Такие файлы видны в фильтре **Все** и не входят в счётчики категорий.

## Поиск

Поле **Поиск по имени или alt** в шапке ищет по названию файла и его описанию. Поиск работает внутри выбранной категории.

## Загрузка

Загрузить файлы можно тремя способами:

1. кнопкой **Загрузить** в шапке;
2. плиткой **Загрузить файлы** в начале сетки;
3. перетащив файлы прямо в окно медиатеки.

Можно выбрать сразу несколько файлов. Они загружаются по очереди, а на кнопке виден счётчик «Загружаю 2 из 5».

Новые файлы попадают в категорию, которая выбрана в фильтре. Если выбран фильтр **Все**, файлы загрузятся без категории. Поэтому удобнее сначала выбрать категорию, а потом загружать.

Принимаются только картинки и видео. Предельный размер файла задаёт проект, и медиатека назовёт его, если файл окажется больше.

## Параметры оптимизации

Шестерёнка открывает параметры, с которыми обрабатываются загружаемые картинки. В списке страниц она стоит справа от фильтров, в окне редактора — рядом с кнопкой **Загрузить**.

![Параметры оптимизации](./images/media-optimize.webp)

| Параметр                      | Что делает                                                             |
| ----------------------------- | ---------------------------------------------------------------------- |
| **Формат**                    | **WebP** переводит картинку в WebP, **Оригинал** сохраняет как есть    |
| **Качество**                  | Степень сжатия при переводе в WebP                                     |
| **Макс. ширина**              | Картинку шире этого значения уменьшат, картинку уже — оставят как есть |
| **Загружать без оптимизации** | Сохраняет файл без обработки, как формат **Оригинал**                  |

Параметры действуют на ближайшие загрузки и в настройки проекта не записываются: при следующем открытии медиатеки вернутся значения по умолчанию. Кнопки «Применить» нет, окно закрывается щелчком мимо него.

Маленькие копии картинки для постепенной загрузки создаются всегда, даже без оптимизации. Как именно картинка проявляется на странице, выбирается у блока Media.

SVG и видео эти параметры не затрагивают. SVG сохраняется как есть, только из него вычищается небезопасный код. Видео не обрабатывается. Анимированные GIF, WebP и AVIF тоже не перекодируются, иначе от анимации остался бы один кадр.

## Свойства файла

Щёлкните по файлу, чтобы открыть его свойства.

![Свойства файла](./images/media-file.webp)

- **Имя** — название файла в медиатеке. Адрес файла от него не зависит. Пустое имя не сохранится, поле вернёт прежнее значение.
- **Alt** — описание картинки для поисковиков и экранных дикторов. У видео не используется.
- **Категория** — одна из созданных категорий или **Без категории**.

Имя и alt сохраняются, когда вы уходите из поля. Отдельной кнопки сохранения нет.

В списке страниц в панели файла ещё есть сведения **О файле** (размер, разрешение, формат, дата загрузки), адрес файла с кнопкой копирования и кнопка **Полноэкранный просмотр**. В окне редактора размер и формат подписаны под полями, а полноэкранный просмотр открывается лупой на плитке.

Корзина удаляет файл навсегда, медиатека переспросит. Удалять файлы может только администратор.

## Выбор файла для блока

1. Выделите блок на канвасе.
2. В панели свойств у поля картинки нажмите **Выбрать**. Откроется медиатека.
3. Щёлкните по нужному файлу и нажмите **Выбрать** в правом нижнем углу.

![Выбор файла для блока](./images/media-picker.webp)

Картинка сразу появится на канвасе. Кнопка **Удалить** рядом с превью отвязывает файл от блока, а сам файл остаётся в медиатеке.

## Какие форматы брать

| Формат   | Когда подходит                                                                    |
| -------- | --------------------------------------------------------------------------------- |
| **WebP** | Фотографии и иллюстрации: хорошее сжатие и качество, прозрачность сохраняется     |
| **SVG**  | Иконки, логотипы, простая графика                                                 |
| **PNG**  | Когда нужен исходный файл без перекодирования: загружайте с форматом **Оригинал** |
