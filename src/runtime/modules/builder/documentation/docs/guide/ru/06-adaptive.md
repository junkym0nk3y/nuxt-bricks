# Адаптивность

Конструктор позволяет проверить и настроить отображение страницы для разных устройств.

## Набор устройств

Набор задаётся проектом, а страница при желании заводит свой. По умолчанию устройств три:

| Устройство  | Ширина |
| ----------- | ------ |
| **Mobile**  | 375px  |
| **Tablet**  | 768px  |
| **Desktop** | 1600px |

Подписи устройств — часть данных страницы, а не интерфейса: они одинаковы на
любом языке и правятся вручную в редакторе набора.

Ширина устройства — это одновременно ширина листа в конструкторе и порог, с которого раскладка применяется на опубликованной странице. Самое узкое устройство обслуживает всё, что уже него, самое широкое — всё, что шире: промежутков между ступенями не остаётся.

### Свой набор для страницы

Откройте **«Настройки»** в левом рейле, найдите группу **«Устройства»** и нажмите **«Настроить устройства»**. В модалке включите тумблер «Свои устройства для этой страницы».

- всего устройств от 2 до 4;
- крайние — самое узкое и самое широкое — удалить нельзя: без них у набора не будет ни нижней, ни верхней границы;
- ширина промежуточного устройства должна попадать строго между крайними;
- меньше 320px не бывает;
- порядок строк задаётся шириной, а не перетаскиванием: строка уезжает на своё место сразу после ввода.

Устройство добавляется выбором из каталога — **Tablet** (768px) или **Laptop** (1280px); занятые и не попадающие между крайними в списке не показываются. Типичный случай — добавить **Laptop** на 1280px: без него окна от 1280 до 1599 получают планшетную раскладку.

Набор той же страницы можно задать заранее — в модалке создания страницы, секция **«Дополнительно»**.

При удалении устройства переопределения свойств, привязанные к нему, удаляются со всех блоков страницы. Подтверждение показывает, сколько их и какому устройству достанется освободившийся диапазон.

## Переключение устройства

Над канвасом расположена панель с переключателями устройств:

![Панель viewport](./images/viewport-panel.png)

Устройства в ней — те же, что в наборе страницы; последняя кнопка, **Figma Like**, показывает все листы набора в ряд.

При переключении ширина канваса изменится, и вы увидите, как страница будет выглядеть на выбранном устройстве.

### Режим Figma Like

Режим **Figma Like** показывает листы всех устройств набора сразу, рядом друг с другом. Удобен, когда нужно сравнить раскладки, не переключаясь между ними. Чем больше устройств в наборе, тем сильнее уменьшается масштаб — четыре листа вписываются примерно в 25%.

> В каждом из представленных адаптивов - внутри канваса есть возможно перемещаться вертикально и горизонтально, как это реализовано в Figma (зажмите на мыше кнопку scroll)

## Скрытие блока на определённом устройстве

Вы можете показывать или скрывать любой блок в зависимости от устройства.

1. Выберите блок на канвасе.
2. В панели свойств найдите секцию **«Отображение»**.
3. В строке **«Показывать на»** выключите ненужное устройство.

**Пример:** слайдер-карусель удобен на мобильных, но на десктопе лучше показать статичную раскладку. Создайте два варианта: слайдер со скрытием на десктопе и Flex-контейнер со скрытием на мобильных.

## Адаптивные свойства layout-контейнеров

Layout-контейнеры **Section**, **Space**, **Media** и **Svg** (а также **Grid** и **Flex**) поддерживают адаптивные настройки — возможность задать разные значения свойств для каждого устройства.

### Как настроить

1. Выберите layout-контейнер на канвасе.
2. В панели свойств над секцией «Свойства» появятся вкладки **Desktop / Tablet / Mobile**.
3. Переключитесь на нужное устройство (например, Mobile).
4. Измените значение свойства — оно будет применяться **только** на выбранном устройстве.
5. Для остальных устройств будет использоваться значение Desktop (базовое).

> При переключении viewport канваса вкладка устройства в панели свойств переключается автоматически. В режиме Figma Like вкладка по умолчанию — Desktop.

### Какие свойства поддерживают адаптивность

Не все свойства адаптивные — только отмеченные в определении. Вот текущий список:

**Section:**

- paddingTop, paddingBottom, paddingX (отступы)
- borderRadius (скругление)
- minHeight (минимальная высота)

**Space:**

- size (величина отступа)
- dividerMarginX (отступы разделителя)

**Media / Svg:**

- width, height (размеры)
- borderRadius (скругление, только Media)

**Grid:**

- columns, rows, gap, variant, rowHeight, minRowHeight

**Flex:**

- direction, justify, wrap, gap

### Пример

Допустим, вы хотите, чтобы секция имела большие отступы на десктопе и маленькие на мобильных:

1. Выберите секцию, убедитесь что вкладка **Desktop** активна.
2. Установите paddingTop = `6` и paddingBottom = `6`.
3. Переключитесь на вкладку **Mobile**.
4. Установите paddingTop = `2` и paddingBottom = `2`.

На опубликованной странице отступы автоматически переключатся через CSS media queries.

## Разные значения свойств для разных устройств (через парные свойства)

Некоторые пользовательские компоненты поддерживают отдельные настройки для каждого устройства через парные свойства в brick-определении. Это позволяет, например, показывать короткий заголовок на мобильных и полный — на десктопе.

Типичные примеры:

- **title** / **mobileTitle** — разные заголовки для десктопа и мобильных.
- **mediaDesktop** / **mediaTablet** / **mediaMobile** — разные изображения для каждого устройства.
- **Слайдов в ряд** у карусели — свойство адаптивное: задайте базовое значение и переопределите его на нужных устройствах.

Если у компонента есть такие парные свойства, они будут видны в панели свойств. Заполните оба поля, чтобы контент корректно отображался на всех устройствах.

> Парные свойства — это подход на уровне компонента (brick). Адаптивные свойства layout-контейнеров (описанные выше) — встроенный механизм билдера, работающий через CSS-переменные и вкладки устройств.

**Совет:** перед публикацией пройдитесь по всем устройствам набора. Режим Figma Like показывает их листы рядом — так расхождения между ступенями заметнее.
