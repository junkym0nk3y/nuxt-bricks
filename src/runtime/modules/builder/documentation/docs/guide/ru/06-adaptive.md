# Адаптивность

Страница одна на все экраны, но выглядеть на телефоне и на компьютере она может по-разному. Для этого у страницы есть набор устройств, а у блоков — свойства, которые задаются отдельно для каждого устройства.

## Набор устройств

По умолчанию устройств три: **Mobile** (375 px), **Tablet** (768 px) и **Desktop** (1600 px). Набор задаёт проект, а отдельная страница может завести свой.

Ширина устройства — это и ширина листа на канвасе, и порог, с которого раскладка устройства включается на опубликованной странице. Самое узкое устройство отвечает за все окна уже него, самое широкое — за все окна шире. Промежутков между ступенями нет.

Названия устройств — часть данных страницы, а не перевод интерфейса. Они одинаковы на любом языке и правятся в редакторе набора.

### Свой набор для страницы

Откройте **Настройки** в левом рейле и в группе **Устройства** нажмите **Настроить устройства**. В окне включите **Свои устройства для этой страницы**.

![Устройства страницы](./images/devices-modal.webp)

| Колонка         | Что задаёт                                                      |
| --------------- | --------------------------------------------------------------- |
| **Устройство**  | Иконку (щелчок по ней открывает выбор) и название               |
| **Ширина, px**  | Ширину листа и порог включения раскладки                        |
| **Отступ, rem** | Боковые поля страницы на этом устройстве                        |
| **Max, rem**    | Наибольшую ширину содержимого страницы. Пусто — без ограничения |
| **Min, rem**    | Наименьшую ширину содержимого страницы. Пусто — без ограничения |

Правила набора:

- устройств от 2 до 4;
- крайние устройства, самое узкое и самое широкое, удалить нельзя: у них замок вместо крестика;
- промежуточное устройство должно быть строго уже самого широкого и шире самого узкого;
- ширина не меньше 320 px;
- добавленное устройство сразу встаёт на своё место по ширине. Если поменять ширину у существующего, полоса диапазонов внизу обновится сразу, а строки таблицы перестроятся при следующем открытии окна.

Кнопка **Добавить устройство** предлагает устройство из каталога: **Tablet** на 768 px или **Laptop** на 1280 px. Занятые и не помещающиеся между крайними в списке не показываются. Частый случай — добавить **Laptop**: без него окна шириной от 1280 до 1599 px получают раскладку планшета.

Полоса **Диапазоны ширины окна** внизу показывает, какое устройство за какие окна отвечает. Рамкой отмечено устройство, открытое сейчас на канвасе.

Если удалить устройство, вместе с ним со всех блоков страницы удалятся его значения свойств. Окно подтверждения скажет, сколько их и какому устройству отойдёт освободившийся диапазон.

Свой набор можно задать и при создании страницы: в окне **Новая страница** раскройте **Дополнительно** и нажмите **Настроить устройства**.

## Просмотр на устройствах

Иконки устройств на панели под канвасом переключают лист канваса. Кнопка **Figma Like** рядом показывает листы всех устройств рядом, чтобы сравнить раскладки без переключения. Чем больше устройств, тем мельче масштаб.

![Режим Figma Like](./images/figma-like.webp)

В режиме Figma Like холст можно двигать средней кнопкой мыши, а масштаб менять через `Ctrl/⌘ + колесо`.

## Скрыть блок на устройстве

1. Выделите блок.
2. В панели свойств, в секции **Отображение**, снимите галочку устройства в строке **Показывать на**.

То же делает пункт **Видимость на устройствах** в контекстном меню блока. Скрытый блок остаётся в схеме, но на этом устройстве посетитель его не увидит.

Например, слайдер удобен на телефоне, а на компьютере лучше смотрится сетка. Поставьте оба блока и скройте слайдер на Desktop, а сетку — на Mobile.

## Значения для отдельного устройства

У выделенного блока вверху панели свойств есть строка **Устройство** с вкладками. На вкладке базового, самого широкого устройства задаются обычные значения. На вкладке другого устройства изменённое значение действует только на нём. Если своего значения у устройства нет, оно берёт базовое.

Когда вы переключаете устройство на канвасе, вкладка в панели переключается вместе с ним.

### Какие свойства адаптивные

| Блок        | Свойства                                                                                                       |
| ----------- | -------------------------------------------------------------------------------------------------------------- |
| **Section** | цвет фона и фоновая картинка, отступы, скругление, минимальная высота, макс. ширина контента                   |
| **Grid**    | колонки и строки, расстояние между элементами, вариант расположения, режим и минимальная высота строк, отступы |
| **Flex**    | направление, выравнивание по обеим осям, расстояние между элементами, перенос строк, отступы                   |
| **Slider**  | слайдов в ряд, отступ между слайдами                                                                           |
| **Space**   | величина и направление отступа, разделитель целиком: показ, цвет, толщина, стиль и отступы от краёв            |
| **Text**    | размер шрифта, отступы                                                                                         |
| **Media**   | ширина, высота, скругление, заполнение                                                                         |
| **Svg**     | ширина, высота, выравнивание, отступы                                                                          |

У аккордеона адаптивных свойств нет.

### Почему остальные поля заблокированы

На вкладке устройства неадаптивные поля видны, но серые, а под вкладками написано, что меняются только адаптивные свойства.

![Заблокированные поля на вкладке устройства](./images/device-tab-locked.webp)

Причина в том, как устроена опубликованная страница: это один HTML, а раскладку под ширину окна выбирают стили. Стилями можно поменять размеры, отступы, цвета, направление и выравнивание. Содержимое так не поменять: текст, файл картинки, режим загрузки и поведение слайдера одинаковы на всех устройствах. Чтобы изменить такое поле, перейдите на вкладку базового устройства, и значение поменяется сразу везде.

Выбор файла из медиатеки тоже всегда меняет базовое значение. Исключение — фоновая картинка секции: она адаптивная, и картинка, выбранная на вкладке Mobile, будет только у Mobile.

### Пример

Секция с большими отступами на компьютере и маленькими на телефоне:

1. Выделите секцию, оставьте вкладку базового устройства.
2. В группе **Отступы** задайте сверху и снизу `6`.
3. Перейдите на вкладку Mobile.
4. Задайте те же отступы `2`.

На опубликованной странице отступы переключатся сами по ширине окна.

### Сбросить значения устройства

Кнопка **Сбросить** справа от строки **Устройство** убирает все значения блока для выбранного устройства, и оно снова берёт базовые. Кнопка появляется, только когда сбрасывать есть что.

![Кнопка «Сбросить» на вкладке устройства](./images/device-reset.webp)

## Разное содержимое на разных устройствах

Встроенные свойства различают по устройствам только оформление. Если нужно разное содержимое, например короткий заголовок на телефоне и длинный на компьютере, это делают разработчики компонента: они добавляют парные поля вроде «Заголовок» и «Заголовок для мобильных». Такие поля видны в панели свойств как обычные, заполните оба.

Перед публикацией пройдитесь по всем устройствам. В режиме Figma Like расхождения между ними заметнее.
