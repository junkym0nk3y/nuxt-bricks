# Layout-контейнеры

Layout-контейнеры — это специальные блоки, которые управляют расположением вложенных элементов. В библиотеке компонентов они находятся в категории **Layout**.

## Как добавить блок внутрь контейнера

1. Добавьте layout-контейнер на канвас из библиотеки компонентов.
2. Перетащите другой блок **прямо на контейнер** — появится подсветка зоны.
3. Отпустите блок внутри подсвеченной области.

## Как убрать блок из контейнера

Перетащите блок за пределы контейнера на свободную область канваса.

## Section — секция

Основной контейнер для группировки блоков. Определяет фон, отступы и скругление для всей секции.

Свойства фона объединены в группу **«Фон»**:

| Свойство            | Описание                                                        |
| ------------------- | --------------------------------------------------------------- |
| **backgroundColor** | Цвет фона (CSS цвет или переменная, например `var(--color-bg)`) |
| **backgroundImage** | Фоновое изображение (выбирается из медиагалереи)                |

Свойства отступов объединены в группу **«Отступы»** и поддерживают адаптивные значения:

| Свойство          | Описание                                |
| ----------------- | --------------------------------------- |
| **paddingTop**    | Внутренний отступ сверху (rem)          |
| **paddingBottom** | Внутренний отступ снизу (rem)           |
| **paddingX**      | Горизонтальные внутренние отступы (rem) |

Остальные свойства:

| Свойство         | Описание                                                                    |
| ---------------- | --------------------------------------------------------------------------- |
| **borderRadius** | Скругление углов секции (rem). Поддерживает адаптивные значения             |
| **minHeight**    | Минимальная высота (rem, 0 = по контенту). Поддерживает адаптивные значения |

## Space — отступ

Создаёт промежуток между блоками. Используйте его, чтобы добавить пространство между секциями страницы.

| Свойство      | Описание                                                                                                |
| ------------- | ------------------------------------------------------------------------------------------------------- |
| **size**      | Величина отступа в rem (например, `2.4` — небольшой, `6.4` — крупный). Поддерживает адаптивные значения |
| **direction** | Направление: `vertical` (вертикальный), `horizontal` (горизонтальный) или `both` (оба направления)      |

Свойства разделителя сгруппированы в секцию **«Разделитель»**:

| Свойство           | Описание                                                             |
| ------------------ | -------------------------------------------------------------------- |
| **showDivider**    | Показать линию-разделитель внутри отступа                            |
| **dividerColor**   | Цвет разделителя (пустое значение = цвет по умолчанию)               |
| **dividerWidth**   | Толщина разделителя в пикселях                                       |
| **dividerStyle**   | Стиль линии: сплошная, пунктирная или точечная                       |
| **dividerMarginX** | Отступы разделителя от краёв (rem). Поддерживает адаптивные значения |

**Совет:** Space — самый простой способ добавить расстояние между секциями страницы.

## Text — текстовый блок

Блок для произвольного текста с HTML-форматированием (жирный, курсив, списки).

| Свойство                     | Описание                             |
| ---------------------------- | ------------------------------------ |
| **content**                  | HTML-контент текстового блока        |
| **marginTop / marginBottom** | Внешние отступы сверху и снизу в rem |

**Совет:** дважды кликните на текстовый блок на канвасе для inline-редактирования.

## Media — медиа-блок

Отображает изображение или видео.

| Свойство           | Описание                                                                      |
| ------------------ | ----------------------------------------------------------------------------- |
| **type**           | Тип контента: `image` или `video`                                             |
| **src**            | Ссылка на файл (выбирается из медиагалереи)                                   |
| **alt**            | Альтернативный текст для доступности                                          |
| **objectFit**      | Масштабирование: `contain`, `cover`, `fill`, `none`, `scale-down`             |
| **width / height** | Размеры (например, `100%`, `auto`, `32rem`). Поддерживают адаптивные значения |
| **borderRadius**   | Скругление углов. Поддерживает адаптивные значения                            |

> Свойства width, height и borderRadius объединены в группу **«Размеры»** и показывают подсказку единицы измерения (rem) рядом с полем ввода.

## Flex — гибкий контейнер

Располагает вложенные блоки в строку или колонку. Удобен для размещения нескольких элементов рядом.

| Свойство                | Описание                                                                               |
| ----------------------- | -------------------------------------------------------------------------------------- |
| **direction**           | `row` (в строку) или `column` (в колонку)                                              |
| **justify**             | Выравнивание по главной оси: `start`, `center`, `end`, `space-between`, `space-around` |
| **align**               | Выравнивание по поперечной оси: `stretch`, `start`, `center`, `end`, `baseline`        |
| **gap**                 | Расстояние между элементами (в пикселях)                                               |
| **wrap**                | Переносить ли элементы на новую строку: `true` / `false`                               |
| **paddingX / paddingY** | Внутренние горизонтальные и вертикальные отступы (в rem)                               |

**Пример:** чтобы разместить список преимуществ и галерею рядом, добавьте Flex с `direction: row`, а затем перетащите оба блока внутрь.

## Grid — сетка

Раскладка в виде сетки с заданным количеством колонок. Подходит для карточек одинакового размера.

| Свойство                | Описание                                                                                             |
| ----------------------- | ---------------------------------------------------------------------------------------------------- |
| **columns**             | Количество колонок (от 1 до 12)                                                                      |
| **rows**                | Количество строк (0 = автоматически)                                                                 |
| **gap**                 | Расстояние между ячейками (в пикселях)                                                               |
| **variant**             | Вариант раскладки: `default` (равномерная), `lead-left` (акцент слева), `lead-right` (акцент справа) |
| **rowHeight**           | Высота строк: `auto`, `1fr`, `min-content`, `max-content`                                            |
| **minRowHeight**        | Минимальная высота строк (в rem)                                                                     |
| **paddingX / paddingY** | Внутренние горизонтальные и вертикальные отступы (в rem)                                             |

## Slider — карусель

Превращает вложенные блоки в слайды карусели. Хорошо подходит для мобильной версии, когда нужно показать несколько карточек с прокруткой.

| Свойство                 | Описание                                 |
| ------------------------ | ---------------------------------------- |
| **slidesPerViewMobile**  | Количество слайдов на экране (мобильные) |
| **slidesPerViewTablet**  | Количество слайдов на экране (планшеты)  |
| **slidesPerViewDesktop** | Количество слайдов на экране (десктоп)   |
| **spaceBetween**         | Расстояние между слайдами (в пикселях)   |
| **loop**                 | Зацикливание карусели: `true` / `false`  |
| **autoplay**             | Автопрокрутка: `true` / `false`          |
| **autoplayDelay**        | Задержка автопрокрутки (в миллисекундах) |
| **showNavigation**       | Показывать стрелки навигации             |
| **showPagination**       | Показывать точки-индикаторы              |

**Совет:** часто слайдер используют только для мобильных устройств, а на десктопе показывают статичную раскладку через Flex или Grid. Для этого скройте слайдер на десктопе через настройку «Показывать на: Desktop» (см. [Адаптивность](./06-adaptive.md)).

## Accordion — аккордеон

Список раскрывающихся элементов. Подходит для FAQ, описания условий или любых блоков с заголовком и скрытым содержимым.

| Свойство              | Описание                                                               |
| --------------------- | ---------------------------------------------------------------------- |
| **items**             | Массив элементов: каждый содержит заголовок и содержимое               |
| **allowMultiple**     | Разрешить открытие нескольких элементов одновременно: `true` / `false` |
| **initialOpenIndex**  | Индекс элемента, открытого по умолчанию (-1 = все закрыты)             |
| **gap**               | Расстояние между элементами в rem (0 = единый блок, >0 = карточки)     |
| **borderRadius**      | Скругление углов элементов (в rem)                                     |
| **accentColor**       | Цвет акцента (полоска или иконка)                                      |
| **animationDuration** | Длительность анимации раскрытия (в мс)                                 |

**Два режима отображения:**

- **Единый блок** (`gap: 0`) — элементы визуально соединены в один список.
- **Карточки** (`gap: > 0`) — каждый элемент выглядит как отдельная карточка с отступом.
