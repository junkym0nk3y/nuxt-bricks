# Layout-блоки

Layout-блоки встроены в конструктор и есть в любом проекте. В библиотеке они собраны в категории **Layout**. Одни раскладывают другие блоки — Section, Grid, Flex, Slider. Другие показывают содержимое сами — Text, Media, Svg, Accordion, Space.

В таблицах ниже поля названы так, как они подписаны в панели свойств. Пометка «адаптивное» значит, что значение задаётся отдельно для каждого устройства, подробнее — в статье [Адаптивность](./06-adaptive.md). Внутренние и внешние отступы у блоков настраиваются в группе **Отступы**: это схема блока с числами по сторонам, она описана в статье [Работа с блоками](./03-components.md).

## Вложение блоков

Чтобы положить блок в контейнер, перетащите его прямо на контейнер: подсветится зона, куда он встанет. Чтобы достать блок, вытащите его за пределы контейнера. Порядок и вложенность удобно править и в панели [Схема](./02-interface.md): строку можно бросить на контейнер.

## Section — секция

Обёртка для смыслового куска страницы: обложки, блока преимуществ, подвала. Задаёт фон, внутренние отступы и ширину содержимого. Внутрь кладутся любые блоки.

| Поле в панели                                 | Что делает                                                                                |
| --------------------------------------------- | ----------------------------------------------------------------------------------------- |
| **CSS color или CSS variable** (группа «Фон») | Цвет фона: код цвета или переменная вроде `var(--bricks-base-900)`. Адаптивное            |
| **Фоновое изображение** (группа «Фон»)        | Картинка из медиатеки, растягивается на всю секцию. Адаптивное                            |
| **Отступы**                                   | Внутренние отступы сверху, снизу и по бокам в `rem`. Адаптивные                           |
| **Макс. ширина контента по центру**           | Ограничивает ширину содержимого и ставит его по центру. `0` — без ограничения. Адаптивное |
| **Скругление углов (rem)**                    | Радиус углов секции. Адаптивное                                                           |
| **Минимальная высота секции**                 | Минимальная высота в `rem`. `0` — по содержимому. Адаптивное                              |

Когда ширина содержимого ограничена, фон, скругление и вертикальные отступы всё равно занимают всю секцию, а боковой отступ работает как минимальное поле. Обложку на всю ширину экрана делают так: у секции включают **Отображать на всю страницу** и задают ей **Макс. ширину контента**.

## Grid — сетка

Раскладка по колонкам и строкам с ячейками одного размера. Подходит для карточек.

| Поле в панели                                         | Что делает                                                                                                                             |
| ----------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| **Размер сетки**                                      | Поле из ячеек и числа **Колонки** (от 1 до 12) и **Строки**. Щелчок по ячейке задаёт оба числа сразу. Адаптивное                       |
| **Расстояние между элементами в пикселях**            | Зазор между ячейками. Адаптивное                                                                                                       |
| **Предустановленные варианты расположения элементов** | **По умолчанию** — все ячейки равны. **Ведущий слева** — первый блок вдвое шире. **Ведущий справа** — вдвое шире последний. Адаптивное |
| **Режим высоты строк грида**                          | **Авто (по контенту)**, **Равные строки (1fr)**, **Минимум контента**, **Максимум контента**. Адаптивное                               |
| **Минимальная высота строки в rem**                   | Нижний предел высоты строки. `0` — без ограничения. Адаптивное                                                                         |
| **Отступы**                                           | Внутренние отступы сетки. Адаптивные                                                                                                   |

Блок встаёт в ту ячейку, над которой его отпустили. Ячеек ровно столько, сколько колонок и строк. Когда все заняты, сетка подсвечивается красным и новый блок не принимает — добавьте строку.

Частый приём — три колонки на компьютере и одна на телефоне. Для этого на вкладке Mobile задайте **Колонки** `1`, а **Строки** — по числу карточек.

## Flex — гибкий контейнер

Ставит вложенные блоки в строку или в столбец. Удобен, когда элементов немного и они разного размера: картинка и текст рядом, ряд кнопок.

| Поле в панели                                         | Что делает                                                                                                                  |
| ----------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| **Направление расположения элементов**                | **Горизонтально** или **Вертикально**. Адаптивное                                                                           |
| **Для row: по горизонтали; для column: по вертикали** | Выравнивание вдоль направления: **В начале**, **По центру**, **В конце**, **Равномерно**, **С отступами**. Адаптивное       |
| **Для row: по вертикали; для column: по горизонтали** | Выравнивание поперёк направления: **Растянуть**, **В начале**, **По центру**, **В конце**, **По базовой линии**. Адаптивное |
| **Расстояние между элементами в пикселях**            | Зазор между блоками. Адаптивное                                                                                             |
| **Перенос строк**                                     | Переносит блоки на новую строку, когда им не хватает места. Адаптивное                                                      |
| **Отступы**                                           | Внутренние отступы контейнера. Адаптивные                                                                                   |

Row — это горизонтальное направление, column — вертикальное.

## Slider — карусель

Превращает вложенные блоки в слайды: каждый блок внутри — отдельный слайд.

| Поле в панели                                                       | Что делает                                                   |
| ------------------------------------------------------------------- | ------------------------------------------------------------ |
| **Слайдов в ряд**                                                   | Сколько слайдов видно одновременно. Адаптивное               |
| **Отступ между слайдами (px)**                                      | Зазор между слайдами. Адаптивное                             |
| **Зациклить слайды**                                                | После последнего слайда снова идёт первый                    |
| **Автопрокрутка**                                                   | Слайды листаются сами                                        |
| **Задержка автопрокрутки (мс)**                                     | Пауза между пролистываниями                                  |
| **Показывать навигацию**                                            | Стрелки по бокам                                             |
| **Показывать пагинацию**                                            | Точки-индикаторы под слайдами                                |
| **Массив объектов [text, subtitle?] для текстовых табов навигации** | Текстовые табы над слайдами или под ними, по одному на слайд |
| **Позиция caption-табов**                                           | **Сверху** или **Снизу**                                     |
| **Клик по табу переключает слайд**                                  | Делает табы кнопками переключения слайдов                    |

Табы задаются списком в формате JSON: у каждого таба есть заголовок `text` и необязательная подпись `subtitle`. Например, `[{"text": "Платья", "subtitle": "Лёгкие ткани"}, {"text": "Обувь"}]` даст два таба. Первый таб относится к первому слайду, второй — ко второму. Пустой список `[]` убирает табы.

Чтобы проверить слайдер в работе, включите у блока **Интерактивный предпросмотр** в контекстном меню или откройте превью страницы.

## Space — отступ

Пустое место между блоками, при желании с линией-разделителем.

| Поле в панели                                         | Что делает                                                             |
| ----------------------------------------------------- | ---------------------------------------------------------------------- |
| **Величина отступа в rem**                            | Размер отступа. Адаптивное                                             |
| **В каком направлении применяется отступ**            | **Вертикально**, **Горизонтально** или **Оба направления**. Адаптивное |
| **Показать разделитель** (группа «Разделитель»)       | Рисует линию внутри отступа. Адаптивное                                |
| **Пустое значение = var(--bricks-base-200)**          | Цвет линии. Пусто — цвет по умолчанию. Адаптивное                      |
| **Толщина разделителя (px)**                          | Толщина линии. Адаптивное                                              |
| **Стиль разделителя**                                 | **Сплошная**, **Пунктирная**, **Точечная**. Адаптивное                 |
| **Горизонтальные отступы разделителя от краёв в rem** | Насколько линия не доходит до краёв. Адаптивное                        |

## Text — текст

Текст с форматированием: заголовки, абзацы, списки, ссылки, картинки.

| Поле в панели     | Что делает                                       |
| ----------------- | ------------------------------------------------ |
| **Контент**       | Сам текст с форматированием                      |
| **Размер шрифта** | Базовый размер текста в `rem`. Адаптивное        |
| **Отступы**       | Внешние отступы блока сверху и снизу. Адаптивные |

Текст удобнее всего править прямо на канвасе: дважды щёлкните по нему. Все способы редактирования описаны в статье [Работа с блоками](./03-components.md).

## Media — изображение или видео

| Поле в панели                                        | Что делает                                                                                                           |
| ---------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| **Тип медиа**                                        | **Изображение** или **Видео**                                                                                        |
| **Источник**                                         | Файл из медиатеки                                                                                                    |
| **Alt текст**                                        | Описание картинки для поисковиков и экранных дикторов                                                                |
| **Заполнение**                                       | Как картинка ложится в рамку: **Вписать**, **Заполнить**, **Растянуть**, **Без масштаба**, **Уменьшить**. Адаптивное |
| **Ширина (rem, %, auto)**, **Высота (rem, %, auto)** | Размеры рамки, группа «Размеры». Адаптивные                                                                          |
| **Скругление углов (rem)**                           | Радиус углов, группа «Размеры». Адаптивное                                                                           |
| **Чем показывать место картинки, пока она грузится** | **Как в настройках модуля**, **Выключено**, **Два этапа: превью → полное**, **Три этапа: mock → превью → полное**    |
| **Первый экран — грузить сразу**                     | Отключает отложенную загрузку. Включайте для картинки, которую видно сразу при открытии страницы                     |

«Заполнить» обрезает картинку по рамке без искажений и подходит для обложек. «Вписать» показывает картинку целиком и оставляет поля.

На вкладке устройства файл, тип и alt не меняются: картинка одна для всех устройств, а по устройствам различаются размеры и заполнение.

## Svg — векторная картинка

Показывает SVG-файл из медиатеки и умеет его перекрашивать. Удобен для иконок и логотипов: один файл подходит к любому фону.

| Поле в панели                           | Что делает                                           |
| --------------------------------------- | ---------------------------------------------------- |
| **Выберите SVG из медиа-галереи**       | Сам файл                                             |
| **Применяется к fill/stroke SVG**       | Цвет заливки и обводки. Пусто — исходные цвета файла |
| **rem или CSS value** (ширина и высота) | Размеры: `4.8rem`, `100%`, `auto`. Адаптивные        |
| **Выравнивание**                        | **Слева**, **По центру**, **Справа**. Адаптивное     |
| **Отступы**                             | Внешние отступы сверху и снизу. Адаптивные           |

## Accordion — аккордеон

Список раскрывающихся пунктов «заголовок и содержимое». Подходит для вопросов и ответов, условий доставки, характеристик.

| Поле в панели                                       | Что делает                                                                             |
| --------------------------------------------------- | -------------------------------------------------------------------------------------- |
| **Элементы**                                        | Пункты аккордеона: у каждого заголовок и содержимое. Кнопка **Добавить** создаёт новый |
| **Открывать несколько**                             | Разрешает раскрыть несколько пунктов одновременно                                      |
| **Индекс элемента, открытого при загрузке**         | Номер пункта, раскрытого сразу, считая с нуля. `-1` — все закрыты                      |
| **Отступ между элементами**                         | `0` — пункты слиты в один список, больше нуля — каждый выглядит отдельной карточкой    |
| **Радиус скругления углов аккордеона или карточек** | Скругление в `rem`                                                                     |
| **Акцентный цвет для hover, бордеров и фона**       | Цвет при наведении, рамок и раскрытого пункта                                          |
| **Длительность анимации раскрытия/закрытия**        | Скорость раскрытия в миллисекундах                                                     |

У аккордеона нет адаптивных полей: на всех устройствах он выглядит одинаково.
