# Интерфейс билдера

Интерфейс конструктора состоит из нескольких областей: верхняя панель управления, левая панель с вкладками и канвас для сборки страницы.

## Верхняя панель (toolbar)

![Верхняя панель](./images/toolbar.png)

Верхняя панель содержит основные действия и название текущей страницы.

### Левая часть

Логотип и название редактируемой страницы. Название — кнопка: она открывает список
страниц проекта с поиском, откуда можно перейти к любой из них, создать новую или
открыть полный менеджер страниц («Все страницы»).

### Правая часть

| Кнопка           | Что делает                                                                   |
| ---------------- | ---------------------------------------------------------------------------- |
| **Сетка**        | Включает визуальную сетку-оверлей на канвасе для точного выравнивания        |
| **Отмена**       | Отменяет последнее действие (`Ctrl/Cmd + Z`)                                 |
| **Повтор**       | Возвращает отменённое действие (`Ctrl/Cmd + Shift + Z`)                      |
| **Медиагалерея** | Загрузка и управление изображениями                                          |
| **Превью**       | Открывает страницу в новой вкладке (работает и с несохранёнными изменениями) |
| **Сохранить**    | Выпадающее меню: «Сохранить изменения» или «Сохранить как копию»             |

## Левая панель навигации

![Боковая навигация](./images/sidebar-nav.png)

Левая панель содержит четыре основные вкладки и две дополнительные кнопки внизу.

### Основные вкладки

| Вкладка        | Что делает                                                             |
| -------------- | ---------------------------------------------------------------------- |
| **Компоненты** | Библиотека блоков для перетаскивания на канвас                         |
| **Свойства**   | Настройки выбранного блока (доступна только при выделенном компоненте) |
| **Схема**      | Древовидная структура всех блоков на странице                          |
| **Настройки**  | Параметры страницы: URL, название, SEO-поля, фон, экспорт/импорт       |

### Нижние кнопки

| Кнопка           | Что делает                                          |
| ---------------- | --------------------------------------------------- |
| **Документация** | Открывает встроенное руководство пользователя       |
| **Тема**         | Переключает между светлой и тёмной темой интерфейса |

> Вкладка **Свойства** становится неактивной, если ни один блок не выделен. При выделении компонента на канвасе вкладка активируется автоматически.

> Рядом с вкладкой **Настройки** может появиться красная точка — это значит, что обязательные поля (URL, название, описание) не заполнены.

## Схема страницы

![Схема страницы](./images/schema-panel.png)

Вкладка **Схема** показывает все блоки страницы в виде списка. Для каждого блока отображаются:

- Название компонента (например, `LandCard`, `Text`, `Space`).
- Иконки быстрых действий: копирование, скрытие на определённом устройстве, удаление.

Схема позволяет быстро находить нужный блок и переходить к его настройкам одним кликом.

## Полотно (канвас)

Канвас — основная рабочая область, на которую вы перетаскиваете компоненты из библиотеки. Здесь формируется будущая страница.

Что можно делать на канвасе:

- **Перетаскивать блоки** из библиотеки компонентов.
- **Менять порядок** блоков перетаскиванием вверх или вниз.
- **Прокручивать** полотно вертикально и горизонтально, зажав колёсико мыши (как в графических редакторах).
- **Выделять блок** кликом — откроется панель свойств слева.
- **Редактировать текст** двойным кликом — для блока Text (подробнее — в статье [Работа с компонентами](./03-components.md)).

При выделении блока над ним появляется тулбар с названием компонента и стрелками для быстрого перемещения.

## Панель viewport

Над канвасом расположена панель управления отображением.

![Панель viewport](./images/viewport-panel.png)

### Режимы viewport

| Режим          | Ширина | Описание                                   |
| -------------- | ------ | ------------------------------------------ |
| **Mobile**     | 375px  | Мобильные устройства                       |
| **Tablet**     | 768px  | Планшеты                                   |
| **Desktop**    | 1600px | Десктопные экраны                          |
| **Figma Like** | 100%   | Занимает всю доступную ширину, как в Figma |

Подробнее о работе с адаптивностью — в статье [Адаптивность](./06-adaptive.md).

> Данные параметры вариативны и наследуются от проекта.

### Масштабирование (зум)

- Кнопки **+** и **-** изменяют масштаб.
- Клик на текущий процент (например, `55%`) сбрасывает масштаб до оптимального значения.
- Также можно использовать лупу для быстрого поиска компонента.

## Горячие клавиши

| Клавиши                  | Действие                              |
| ------------------------ | ------------------------------------- |
| `Delete` или `Backspace` | Удалить выбранный блок                |
| `Ctrl/Cmd + C`           | Копировать блок                       |
| `Ctrl/Cmd + V`           | Вставить блок                         |
| `Ctrl/Cmd + Z`           | Отменить действие                     |
| `Ctrl/Cmd + Shift + Z`   | Повторить действие                    |
| `Escape`                 | Выйти из режима редактирования текста |
