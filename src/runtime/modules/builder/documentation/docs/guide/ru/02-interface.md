# Интерфейс редактора

Редактор состоит из четырёх зон: верхней панели, левого рейла с панелями, канваса с плавающей панелью управления и панели свойств справа.

![Редактор страницы](./images/editor-overview.webp)

## Верхняя панель

Слева находятся логотип и название страницы:

- **Логотип** открывает список всех страниц в новой вкладке, а редактор остаётся открытым.
- **Название страницы** раскрывает список страниц проекта. Из него можно перейти к другой странице, открыть **Все страницы** или **Создать страницу**. Черновики помечены меткой «Черновик».

![Список страниц в редакторе](./images/page-selector.webp)

Справа расположены кнопки:

| Кнопка                  | Что делает                                                                                   |
| ----------------------- | -------------------------------------------------------------------------------------------- |
| **Загружаемый контент** | Открывает [медиатеку](./05-media.md)                                                         |
| **Посмотреть превью**   | Открывает страницу в новой вкладке вместе с несохранёнными правками                          |
| **Сохранить**           | Раскрывает меню: **Сохранить изменения**, **Сохранить как копию** и **Сохранить как шаблон** |
| **Аватар**              | Меню профиля: **Профиль** и **Выйти**                                                        |

![Меню сохранения](./images/save-menu.webp)

Что делает каждый пункт сохранения, рассказано в статье [Настройки и публикация](./08-publishing.md).

## Левый рейл

| Кнопка           | Что открывает                                                                |
| ---------------- | ---------------------------------------------------------------------------- |
| **Компоненты**   | Библиотеку блоков для перетаскивания на канвас                               |
| **Схема**        | Дерево всех блоков страницы                                                  |
| **Настройки**    | Настройки страницы: адрес, SEO, код, устройства, OG-картинку, фон, навигацию |
| **Документация** | Это руководство                                                              |
| **RU / EN**      | Переключает язык интерфейса                                                  |
| **Луна, солнце** | Тёмную или светлую тему интерфейса                                           |

Повторный щелчок по кнопке активной панели закрывает её. Красная точка у **Настроек** значит, что у страницы не заполнены обязательные поля.

Документация пока написана только на русском. В английском интерфейсе вместо статей показывается заглушка.

Тёмная тема меняет только интерфейс. Канвас остаётся светлым: он показывает страницу так, как её увидят посетители.

![Редактор в тёмной теме](./images/editor-dark.webp)

## Канвас

Канвас показывает страницу на листе выбранного устройства.

- **Щелчок** по блоку выделяет его и открывает панель свойств.
- **Двойной щелчок** по тексту включает его редактирование прямо на канвасе.
- **Правый щелчок** открывает контекстное меню блока: копирование, дублирование, видимость на устройствах и другие действия. Меню разобрано в статье [Работа с блоками](./03-components.md).
- Блок можно перетащить по канвасу, чтобы поменять порядок или переложить его в другой контейнер.

Навигация по холсту:

- **колесо мыши** прокручивает страницу, **Shift + колесо** — по горизонтали;
- **Ctrl/⌘ + колесо** или щипок на тачпаде меняют масштаб относительно курсора;
- если зажать **среднюю кнопку мыши**, холст можно тянуть, как в графических редакторах.

## Панель под канвасом

![Панель под канвасом](./images/bottom-bar.webp)

| Элемент            | Что делает                                                                          |
| ------------------ | ----------------------------------------------------------------------------------- |
| Иконки устройств   | Переключают лист канваса на устройство из набора страницы                           |
| **Figma Like**     | Показывает листы всех устройств рядом                                               |
| Лупы **−** и **+** | Отдаляют и приближают                                                               |
| Процент масштаба   | Возвращает масштаб, при котором лист вписан в окно                                  |
| Стрелки            | Шаг назад (`Ctrl/⌘ + Z`) и шаг вперёд (`Ctrl/⌘ + Shift + Z`)                        |
| **Сетка**          | Показывает контуры контейнеров и ячейки сеток. Помогает целиться при перетаскивании |

Сетка включена по умолчанию. Устройства и режим Figma Like подробно описаны в статье [Адаптивность](./06-adaptive.md).

## Панель свойств

Справа открываются настройки выделенного блока: вкладки устройств, секция **Отображение** и свойства самого блока. Панель закрывается крестиком или клавишей `Escape`, выделение при этом снимается. Поля панели разобраны в статье [Работа с блоками](./03-components.md).

## Схема страницы

![Схема страницы](./images/schema-panel.webp)

Панель **Схема** показывает блоки страницы деревом. Вложенные блоки стоят с отступом под своим контейнером.

- Щелчок по строке выделяет блок.
- Строку можно перетащить. Выше или ниже соседа — чтобы поменять порядок, на контейнер — чтобы вложить блок в него. Если так переместить нельзя, например в сетке не осталось свободных ячеек, схема объяснит причину.
- Иконки устройств справа показывают, где блок виден. Потускневшая иконка значит, что на этом устройстве блок скрыт. Значок глаза отмечает отключённый блок.
- Значок сетки перед именем отмечает layout-блок, значок пазла — компонент проекта.

## Горячие клавиши

| Клавиши                  | Действие                                                                 |
| ------------------------ | ------------------------------------------------------------------------ |
| `Delete` или `Backspace` | Удалить выделенный блок                                                  |
| `Ctrl/⌘ + C`             | Копировать блок                                                          |
| `Ctrl/⌘ + V`             | Вставить скопированный блок                                              |
| `Ctrl/⌘ + Z`             | Шаг назад                                                                |
| `Ctrl/⌘ + Shift + Z`     | Шаг вперёд                                                               |
| `Escape`                 | Снять выделение и закрыть панель свойств, выйти из редактирования текста |

Клавиши не срабатывают, пока курсор стоит в поле ввода или открыто окно. У роли «Наблюдатель» работает только `Escape`.
