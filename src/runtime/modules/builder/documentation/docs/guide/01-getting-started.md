# Начало работы

Конструктор лендингов позволяет собирать посадочные страницы из готовых блоков без написания кода. Вы перетаскиваете компоненты на полотно, настраиваете их свойства и публикуете результат.

## Стартовая страница

Перейдите по адресу `/builder` в браузере. Вы увидите два варианта:

1. **Создать новую страницу** — откроет пустой редактор, где вы начнёте собирать лендинг с нуля.
2. **Открыть список страниц** — покажет все сохранённые страницы. Вы сможете перейти к редактированию любой из них или посмотреть превью.

![Стартовая страница](./images/start-page.png)

## Первые шаги

1. Нажмите **Создать новую страницу**.
2. Откройте **Настройки** в левой панели и заполните параметры страницы: URL, название и описание (подробнее — в статье [Сохранение и публикация](./07-publishing.md)).
3. Нажмите **Компоненты** в левой панели — откроется библиотека блоков.
4. Перетащите нужный блок на канвас.
5. Нажмите на блок — в левой панели автоматически откроется вкладка **Свойства**. Настройте содержимое.
6. Нажмите **Сохранить** в верхней панели.

Готово — ваша первая страница создана. Далее вы можете добавлять новые блоки, настраивать их расположение с помощью [layout-контейнеров](./04-layouts.md) и проверять, как страница выглядит на разных устройствах (см. [Адаптивность](./06-adaptive.md)).

## Обзор интерфейса

![Обзор интерфейса билдера](./images/builder-overview.png)

Интерфейс состоит из трёх основных зон:

- **Верхняя панель** — кнопки управления: сетка, отмена/повтор, редактор страниц, медиагалерея, превью и сохранение.
- **Левая панель** — четыре вкладки: Компоненты, Свойства, Схема и Настройки.
- **Канвас** — основная рабочая область, куда перетаскиваются блоки.

Подробнее о каждой зоне — в статье [Интерфейс билдера](./02-interface.md).
