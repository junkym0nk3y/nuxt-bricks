# Getting Started

The landing page builder lets you assemble pages from ready-made blocks without writing code. You drag components onto the canvas, configure their properties, and publish the result.

## Start page

Open `/builder` in your browser. You will see two options:

1. **Create a new page** — opens an empty editor where you build a landing page from scratch.
2. **Open the page list** — shows all saved pages. You can continue editing any of them or open a preview.

![Start page](./images/start-page.png)

## First steps

1. Click **Create a new page**.
2. Open **Settings** in the left panel and fill in the page parameters: URL, title, and description.
3. Click **Components** in the left panel — the block library opens.
4. Drag the block you need onto the canvas.
5. Click the block — the **Properties** tab opens automatically in the left panel. Configure the content.
6. Click **Save** in the top toolbar.

Done — your first page is created. Next, you can add more blocks, arrange them with layout containers, and check how the page looks on different devices.

## Interface overview

![Builder interface overview](./images/builder-overview.png)

The interface consists of three main areas:

- **Top toolbar** — control buttons: grid, undo/redo, page editor, media gallery, preview, and save.
- **Left panel** — four tabs: Components, Properties, Schema, and Settings.
- **Canvas** — the main working area where blocks are dropped.
