# Getting Started

The landing page builder lets you assemble pages from ready-made blocks without writing code. You drag components onto the canvas, configure their properties, and publish the result.

## Pages manager

Open `/bricks` in your browser — the pages manager appears. It is the single control center: the list of all pages with search and filters (All / Published / Drafts), a details panel with the selected page settings, and a button to create a new page.

The left rail contains the **Pages** and **Templates** sections, plus **Media** (media gallery), **Documentation**, a dark theme toggle, and the interface language switcher.

## First steps

1. Click **+ Create page** in the manager header.
2. Fill in the title — the URL (slug) is generated automatically, edit it if needed — and the description. Click **Create**: an empty editor opens.
3. Click **Components** in the left panel — the block library opens.
4. Drag the block you need onto the canvas.
5. Click the block — the **Properties** tab opens automatically in the left panel. Configure the content.
6. Click **Save** in the top toolbar.

Done — your first page is created. Next, you can add more blocks, arrange them with layout containers, and check how the page looks on different devices. Other page parameters (URL, meta description, publishing) can be edited both in the editor — the **Settings** tab — and in the details panel of the pages manager.

## Editor interface overview

![Builder interface overview](./images/builder-overview.png)

The interface consists of three main areas:

- **Top toolbar** — control buttons: grid, undo/redo, pages manager, media gallery, preview, and save.
- **Left panel** — four tabs: Components, Properties, Schema, and Settings.
- **Canvas** — the main working area where blocks are dropped.
