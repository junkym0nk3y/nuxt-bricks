# common/utils

Общие утилиты (используются 2+ доменами).

| Файл / папка                   | Назначение                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| ------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `main.ts`                      | px ↔ rem конверсии, hex-валидация/нормализация, `normalizeBricksError`, `isStatementTimeoutError` (debounce — `useDebounceFn` из `@vueuse/core`)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `dragAndDrop.ts`               | Разбор drag-payload (`applyDropEffect` — единая политика `dropEffect` для канваса, слотов и layout-зон) и `measureDragSize` — фактический размер блока для drag-визуалов                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `case-transform.ts`            | Конвертация snake_case ↔ camelCase (нормализация ответов Django backend)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `cookieHeader.ts`              | `stripCookieByName` — фильтрация заголовка Cookie перед проксированием на внешний backend (cookie сессии bricks не пробрасывается; ssrRequestHeaders + proxy middleware)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `ssrRequestHeaders.ts`         | Проброс заголовков входящего SSR-запроса в API-запрос билдера: список пробрасываемых (`pickForwardedHeaders`), снятие identity инсталляции для внешнего endpoint (`toExternalHeaders` — cookie сессии и `Authorization`) и её возврат локальным `/api/bricks/**` (`pickIdentityHeaders`), которым editorial API без неё отвечает 401                                                                                                                                                                                                                                                                                                                                                      |
| `apiRequestPolicy.ts`          | Политика запросов всех трёх транспортов (клиент билдера, lookup published-страницы, data sources): потолок ожидания по HTTP-методу (`resolveApiRequestTimeout`), применение к опциям запроса живым сигналом на обе фазы ответа (`applyApiRequestTimeout`) и распознавание обрыва по таймауту через цепочку `cause` (`isRequestTimeoutError`); `CLIENT_OWNED_REQUEST_OPTIONS` — опции транспорта, недоступные вызывающему (хуки и повторы: они действуют после решения маршрутизации и уводят авторизованный запрос на другой адрес), единственный источник и для типа опций, и для снятия в рантайме                                                                                      |
| `abortSignals.ts`              | `createTimeoutSignal` — потолок ожидания сигналом (опция `timeout` ofetch снимается на заголовках и зависшее тело не ограничивает), с fallback'ом и защитой от мусорных значений конфигурации; `combineAbortSignals` — сведение потолка и отмены вызывающего в один сигнал                                                                                                                                                                                                                                                                                                                                                                                                                |
| `promiseDeadline.ts`           | `withPromiseDeadline` — wall-clock дедлайн вокруг промиса для SSR-путей, где `AbortSignal` инертен: внутренний вызов Nitro сигнал не слушает, поэтому зависший обработчик можно только перестать ждать                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `localApiPaths.ts`             | Чистые предикаты локальных API-путей (`/api/bricks/**` — segment-boundary): единственная копия правила для useApiClient и серверного devProxy-роутинга                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `safeRecord.ts`                | `hasOwnKey`/`readOwnKey`/`toSafeRecord` — доступ к объектам по ключу из схемы, brick-файла или ответа data source: имена членов `Object.prototype` (`__proto__`, `constructor`, `toString`) не должны читаться как существующие значения и не должны уходить в глобальный прототип                                                                                                                                                                                                                                                                                                                                                                                                        |
| `slug.ts`                      | `labelToSlug` — подпись пользователя в машинный идентификатор (транслитерация кириллицы, NFKC): общая для slug'ов медиа-категорий и ключей устройств                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `i18nLabels.ts`                | `resolveBricksLabel` — перевод ключей `bricks.*` из definitions, кастомные строки потребителя проходят как есть                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `bricks/paths.ts`              | Нормализация путей brick-файлов (POSIX-слэши)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `bricks/components.ts`         | Глубокие копии пропсов для истории/drag&drop; единственная точка, где own-ключ `__proto__` отбрасывается на входе схемы в стор — в Nuxt payload он непредставим                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `bricks/devices.ts`            | Набор устройств: `validateDeviceSet` (недоверенный вход отклоняется целиком, а не чинится сортировкой), `resolveDeviceSet` (набор страницы поверх проектного, повреждённый — заменяется проектным), `deviceRanges`, `cloneDeviceSet` (копия из простых объектов: снимает reactive-обёртку, которую structured clone в `postMessage` не переносит), `resolveDeviceIcon` (короткий ключ глифа → имя реестра иконок префиксом)                                                                                                                                                                                                                                                               |
| `bricks/deviceVisibility.ts`   | Нормализация конфигурации видимости по устройствам                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| `bricks/publishedPage.ts`      | `normalizePublishedPage`/`normalizePublishedPageSummary` (+ `isBricksSchema`, `preserveSchema`) — единая копия для store и middleware, новые поля `IPublishedPage` добавлять только здесь; `normalizePageVersionPreview` — снапшот версии под тождеством текущей строки; `matchesPageSubdomain` — соответствие субдомена хосту запроса                                                                                                                                                                                                                                                                                                                                                    |
| `bricks/pageAddress.ts`        | Адресная идентичность страницы (`urlPrefix` + `pagename`): нормализация префикса, канонический ключ (`getPageAddressKey` — им же строятся ключи черновиков, SSR-payload и data sources), сравнение адресов, разбор параметров маршрута и обратная сборка named-локации, `isValidPageAddress` — общий формат для формы, DTO и публичного lookup'а. Единственный владелец сериализации адреса: вторая копия правила разошлась бы с ключами и путями                                                                                                                                                                                                                                         |
| `bricks/previewRoute.ts`       | Превью-роуты (с префиксом адреса и без): `PREVIEW_VERSION_QUERY_PARAM` + `parsePreviewVersionId` (версия живёт в URL, а не в единственном слоте localStorage), `getBricksPageDataKey` — общий ключ payload'а для middleware и страницы рендера (строится от АДРЕСА: по одному имени SPA-переход между одноимёнными страницами отдавал 404), `getRenderPageKey` — page key рендера (версия входит в него только на превью-роуте)                                                                                                                                                                                                                                                           |
| `bricks/routePaths.ts`         | Префиксы поверхностей (`bricks.routes`): построение/матчинг путей билдера и превью, strip/join `app.baseURL`, `validateBricksRoutePrefixes` (fail-fast в module.ts); построение адресных путей (`getPublishedPagePath`, `getBuilderPagePath`, `getPreviewPagePath` — все от ключа адреса); доступность адресов страницы по роутингу — `isPageAddressTaken` (live-адрес: чужой маршрут или поддерево поверхности за auth) и `isEditorAddressTaken` (адрес редактора занял статический сосед; проверяется пара, а не имя), владельца пути даёт резолвер: в браузере `router.resolve` (`useBricksPageAddress`), на сервере `getBricksOwnStaticRoutes`; хардкод `/bricks`/`/preview` запрещён |
| `bricks/assetPaths.ts`         | `resolveBricksAssetUrl` — URL публичных ассетов модуля (`/_bricks/` + `app.baseURL`): превью layout-блоков, плейсхолдер, картинки документации; хардкод `/images/...` запрещён                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| `bricks/schemaContract.ts`     | `validateSchemaComponentGraph` — структурный контракт графа компонентов схемы (форма, уникальность id, двусторонние связи, ацикличность, глубина); `isRenderableSchemaComponent`, `MAX_COMPONENT_TREE_DEPTH` — защитные примитивы рендера. Используется server-валидацией payload/restore, импортом JSON билдера и рендером                                                                                                                                                                                                                                                                                                                                                               |
| `sanitize/sanitizeRichText.ts` | `sanitizeRichTextHtml` — allow-list санитайзер TipTap-HTML перед каждым `v-html` (изоморфный, js-xss)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `sanitize/sanitizeSvg.ts`      | `sanitizeSvgMarkup` — allow-list санитайзер inline SVG (BlockSvg, сегменты, svgContent медиа на записи)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `sanitize/urlPolicy.ts`        | Чистые URL-политики без DOM, общие для обоих санитайзеров: локальные `url(#fragment)`-ссылки для `filter`/`clip-path`/`mask`/`fill`/`stroke`/`style`, `SAFE_LINK_PATTERN`/`SAFE_MEDIA_SRC_PATTERN` (rich text `href`/`src`/`poster`, запрет protocol-relative `//host`)                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `bricks/containerCss.ts`       | `buildBricksContainerCss` — CSS `.bricks-container` по набору устройств: канвас адресуется `data-bricks-viewport`, published — диапазонами набора                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
