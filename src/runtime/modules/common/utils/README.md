# common/utils

Shared utilities (used by 2+ domains).

| File / folder                  | Purpose                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| ------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `main.ts`                      | The px ↔ rem conversions, hex validation/normalization, `normalizeBricksError`, `isStatementTimeoutError` (for debounce there is `useDebounceFn` out of `@vueuse/core`)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `dragAndDrop.ts`               | Reading a drag payload (`applyDropEffect` — the single `dropEffect` policy for the canvas, the slots and the layout zones) and `measureDragSize` — the actual size of a block for the drag visuals                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `case-transform.ts`            | Conversion between snake_case and camelCase (normalizing the responses of a Django backend)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `cookieHeader.ts`              | `stripCookieByName` — filtering the Cookie header before proxying to an external backend (the bricks session cookie is not forwarded; ssrRequestHeaders + the proxy middleware)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `ssrRequestHeaders.ts`         | Forwarding the headers of an incoming SSR request into an API request of the builder: the list of what is forwarded (`pickForwardedHeaders`), stripping the installation's identity for an external endpoint (`toExternalHeaders` — the session cookie and `Authorization`) and returning it to the local `/api/bricks/**` (`pickIdentityHeaders`), which the editorial API answers 401 without                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `apiRequestPolicy.ts`          | The request policy of all three transports (the builder's client, the lookup of a published page, the data sources): the waiting ceiling by HTTP method (`resolveApiRequestTimeout`), applying it to the request options with a live signal over both phases of the response (`applyApiRequestTimeout`) and recognizing an abort by timeout through the `cause` chain (`isRequestTimeoutError`); `CLIENT_OWNED_REQUEST_OPTIONS` — the transport options the caller may not have (the hooks and the retries: they act after the routing decision and take an authorized request to a different address), the single source both of the options type and of the runtime stripping                                                                                                                                                  |
| `abortSignals.ts`              | `createTimeoutSignal` — a waiting ceiling as a signal (the `timeout` option of ofetch is lifted at the headers and bounds no hung body), with a fallback and a guard against junk configuration values; `combineAbortSignals` — collapsing the ceiling and the caller's cancellation into one signal                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `promiseDeadline.ts`           | `withPromiseDeadline` — a wall-clock deadline around a promise for the SSR paths where an `AbortSignal` is inert: an internal Nitro call does not listen to a signal, so the only thing left from the outside is to stop waiting for it                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `localApiPaths.ts`             | The pure predicates of the local API paths (`/api/bricks/**` — on a segment boundary): the single copy of the rule for useApiClient and for the server's devProxy routing                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| `safeRecord.ts`                | `hasOwnKey`/`readOwnKey`/`toSafeRecord` — access to objects by a key that comes out of a schema, a brick file or a data source response: the member names of `Object.prototype` (`__proto__`, `constructor`, `toString`) must not read as existing values and must not travel into the global prototype                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `slug.ts`                      | `labelToSlug` — a person's label into a machine identifier (transliteration of Cyrillic, NFKC): shared by the slugs of the media categories and the keys of the devices                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `transitionInert.ts`           | `markLeavingInert` — putting out the interactivity of a node leaving by a leave animation: `pointer-events` closes the pointer alone, while the keyboard and assistive tech reach into a leaving modal and a leaving screen of the dashboard (a transition is sometimes automatic, and the focus stays inside). There is no removal of the attribute: a `v-if` node is not reused — Vue cuts the leave of the previous one short and creates a new one                                                                                                                                                                                                                                                                                                                                                                           |
| `globalI18n.ts`                | `translateBricksKey` — translating through the global i18n for code with no setup context (the stores and what they call): `$i18n` is read lazily, a missing instance gives the key back instead of throwing                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `i18nLabels.ts`                | `resolveBricksLabel` — translating the `bricks.*` keys out of the definitions, a consumer's custom strings pass through as they are                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `bricks/paths.ts`              | Normalizing the paths of brick files (POSIX slashes)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `bricks/components.ts`         | Deep copies of the props for the history and for drag and drop; the single point where the own key `__proto__` is dropped at the schema's entry into the store — in a Nuxt payload it cannot be represented                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `bricks/devices.ts`            | The device set: `validateDeviceSet` (untrusted input is rejected whole rather than fixed by sorting), `resolveDeviceSet` (a page's set over the project's one, a broken one is replaced by the project's), `deviceRanges`, `cloneDeviceSet` (a copy made of plain objects: it takes off the reactive wrapper that the structured clone of a `postMessage` does not carry), `resolveDeviceIcon` (a short glyph key → a name of the icon registry, by prefix)                                                                                                                                                                                                                                                                                                                                                                      |
| `bricks/deviceVisibility.ts`   | Normalizing the per-device visibility configuration                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `bricks/publishedPage.ts`      | `normalizePublishedPage`/`normalizePublishedPageSummary` (+ `isBricksSchema`, `preserveSchema`) — the single copy for the store and the middleware, new fields of `IPublishedPage` are to be added here only; `normalizePageVersionPreview` — a version's snapshot under the identity of the current row; `matchesPageSubdomain` — whether a subdomain matches the host of the request                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `bricks/pageAddress.ts`        | The address identity of a page (`urlPrefix` + `pagename`): normalizing the prefix, the canonical key (`getPageAddressKey` — the keys of the drafts, the SSR payload and the data sources are built out of it too), comparing addresses, reading the route params and assembling a named location back, `isValidPageAddress` — the shared format for the form, the DTO and the public lookup. The single owner of the address serialization: a second copy of the rule would drift away from the keys and the paths                                                                                                                                                                                                                                                                                                               |
| `bricks/previewRoute.ts`       | The preview routes (with the address prefix and without): `PREVIEW_VERSION_QUERY_PARAM` + `parsePreviewVersionId` (a version lives in the URL rather than in the single slot of localStorage), `getBricksPageDataKey` — the shared payload key for the middleware and the render page (built out of the ADDRESS: by the name alone an SPA move between two same-named pages answered 404), `getRenderPageKey` — the page key of the render (a version enters it on a preview route only)                                                                                                                                                                                                                                                                                                                                         |
| `bricks/routePaths.ts`         | The prefixes of the surfaces (`bricks.routes`): building and matching the paths of the builder and of the preview, stripping and joining `app.baseURL`, `validateBricksRoutePrefixes` (fail-fast in module.ts); building the address paths (`getPublishedPagePath`, `getBuilderPagePath`, `getPreviewPagePath` — all off the address key); whether the addresses of a page are available by the routing — `isPageAddressTaken` (the live address: someone else's route or a subtree of a surface behind auth) and `isEditorAddressTaken` (the editor's address is taken by a static neighbor; the pair is checked, not the name); the owner of a path is given by the resolver: in the browser `router.resolve` (`useBricksPageAddress`), on the server `getBricksOwnStaticRoutes`; hardcoding `/bricks`/`/preview` is forbidden |
| `bricks/assetPaths.ts`         | `resolveBricksAssetUrl` — the URLs of the module's public assets (`/_bricks/` + `app.baseURL`): the previews of the layout blocks, the placeholder, the pictures of the documentation; hardcoding `/images/...` is forbidden                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `bricks/dates.ts`              | The date format of the dashboard's interface: `formatPageDate` → `DD.MM.YYYY`, `formatPageDateTime` → `+ HH:mm`. Shared by the pages list and the templates grid; the date of a page's saved version is `publish/utils/dates.ts`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| `bricks/schemaContract.ts`     | `validateSchemaComponentGraph` — the structural contract of a schema's component graph (the shape, the uniqueness of the ids, the two-way links, acyclicity, the depth); `isRenderableSchemaComponent`, `MAX_COMPONENT_TREE_DEPTH` — the defensive primitives of the render. Used by the server validation of a payload and of a restore, by the JSON import of the builder and by the render                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `bricks/containerCss.ts`       | `buildBricksContainerCss` — the `.bricks-container` CSS for a device set: the canvas is addressed by `data-bricks-viewport`, published by the ranges of the set                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `sanitize/index.ts`            | The public entry `nuxt-bricks/sanitize` — the re-export of both sanitizers for the consumer's own brick components that render raw HTML/SVG                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `sanitize/sanitizeRichText.ts` | `sanitizeRichTextHtml` — the allow-list sanitizer of TipTap HTML ahead of every `v-html` (isomorphic, js-xss)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `sanitize/sanitizeSvg.ts`      | `sanitizeSvgMarkup` — the allow-list sanitizer of an inline SVG (BlockSvg, the segments, the svgContent of media on a write)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `sanitize/urlPolicy.ts`        | The pure URL policies with no DOM, shared by both sanitizers: the local `url(#fragment)` references for `filter`/`clip-path`/`mask`/`fill`/`stroke`/`style`, `SAFE_LINK_PATTERN`/`SAFE_MEDIA_SRC_PATTERN` (the `href`/`src`/`poster` of rich text, the ban on a protocol-relative `//host`)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `sanitize/xssInterop.ts`       | The CJS bridge to js-xss: the package overwrites its own exports, so `FilterXSS` and `safeAttrValue` are taken out of module.exports by a default import — the one path that holds both in production Node ESM and in vite-node dev SSR                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
