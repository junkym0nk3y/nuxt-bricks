# common/utils

Общие утилиты (используются 2+ доменами).

| Файл / папка                   | Назначение                                                                                                                                                                                                                                                                                   |
| ------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `main.ts`                      | px ↔ rem конверсии, hex-валидация/нормализация, `normalizeBricksError` (debounce — `useDebounceFn` из `@vueuse/core`)                                                                                                                                                                        |
| `case-transform.ts`            | Конвертация snake_case ↔ camelCase (нормализация ответов Django backend)                                                                                                                                                                                                                     |
| `cookieHeader.ts`              | `stripCookieByName` — фильтрация заголовка Cookie перед проксированием на внешний backend (cookie сессии bricks не пробрасывается; useApiClient + proxy middleware)                                                                                                                          |
| `i18nLabels.ts`                | `resolveBricksLabel` — перевод ключей `bricks.*` из definitions, кастомные строки потребителя проходят как есть                                                                                                                                                                              |
| `bricks/paths.ts`              | Нормализация путей brick-файлов (POSIX-слэши)                                                                                                                                                                                                                                                |
| `bricks/components.ts`         | Глубокие копии пропсов для истории/drag&drop                                                                                                                                                                                                                                                 |
| `bricks/deviceVisibility.ts`   | Нормализация конфигурации видимости по устройствам                                                                                                                                                                                                                                           |
| `bricks/publishedPage.ts`      | `normalizePublishedPage`/`normalizePublishedPageSummary` (+ `isBricksSchema`, `preserveSchema`) — единая копия для store и middleware, новые поля `IPublishedPage` добавлять только здесь; `resolveRequestedUrlPrefix`/`matchesPageUrlPrefix` — соответствие URL catch-all маршрута странице |
| `bricks/routePaths.ts`         | Префиксы поверхностей (`bricks.routes`): построение/матчинг путей билдера и превью, strip/join `app.baseURL`, `validateBricksRoutePrefixes` (fail-fast в module.ts); хардкод `/bricks`/`/preview` запрещён                                                                                   |
| `sanitize/sanitizeRichText.ts` | `sanitizeRichTextHtml` — allow-list санитайзер TipTap-HTML перед каждым `v-html` (изоморфный, js-xss)                                                                                                                                                                                        |
| `sanitize/sanitizeSvg.ts`      | `sanitizeSvgMarkup` — allow-list санитайзер inline SVG (BlockSvg, сегменты, svgContent медиа на записи)                                                                                                                                                                                      |
| `routing/`                     | Build-time/CLI: `generate-bricks-json.ts` (bricks.json; CLI-копия — `src/cli/`), `vite-brick-watch.ts` (HMR `.brick.ts`), `bricks-api.ts` (чтение bricks.json по категориям)                                                                                                                 |
